## 6. 对 LifeSim 任务的具体影响

- **M3-003 程序化事件目录与双语叙事框架**：采用 R3 的字段结构（年龄区间、条件、年概率、类别、出处）但落成 zod schema + 事件目录 + 双语模板；不采用 I1 的正则替换。
- **M3-011/012/013**：时代差异通过国家包字段与年代分段表达，不用 I1。
- **M3-014/015**：采用 R4/R5 的校准思路；系数与死因权重必须来自可核查来源或标为 D 级并在 ADR 记录推导。
- **M3-021…025**：五国事件各自独立设计；日本可参考 R3/I3 的**组织方式**（年代分段、生活细节、事件出处），文案与数值另写。
- **M4-005/006/007**：参考 R6 的「多数人会这样选」、I3 的时代化决策卡、I4 的按年分组；实现必须用 React + 虚拟列表。
- **M4-001/002**：存档仍用「快照 + 事实日志 + 校验和」，**不采用** R2 的纯回放方案（规则变更会让回放漂移，而快照契约有版本拒绝机制）。

## 7. 无法确认许可的内容（不得进入 LifeSim）

1. 字体：Noto Sans JP / Shippori Mincho / Zen Kurenaido 经 Google Fonts CDN 加载；仓库无 OFL 文本与 NOTICE；`.gitignore` 忽略 `server/fonts/`。LifeSim 只用系统字体，不引入。
2. 地图：国土地理院「地球地図日本」经 dataofjapan/land 加工，再分发条件与「加工著作」定性未确认。
3. Geolonia `japanese-addresses`（标注 CC BY 4.0）：未给出数据集版本与修改说明，归属合规性未确认。
4. 二手统计表：名字由来net、みんなの高校情報、河合塾偏差值代表值、マイナビ/日経ランキング、オリコン、日语维基百科等；抓取与再分发许可未确认。
5. 偏差值、年收等「概算」值：无来源与许可声明。
6. 谱面：`clair.js` 由 Mutopia（公有领域曲目）转换，转换链与谱面数据许可未确认。
7. `server/lifelog.py` 的 OG 图与用户投稿数据政策未说明。
8. 作者身份仅为 `satoru.net`，MIT 归属对象的可执行性未确认（形式上保留原文即可）。

**结论**：只允许复用代码，不允许复用数据与素材；任何代码复用都必须逐文件登记。

## 8. 复用登记流程（强制）

如果后续任务决定复制或移植 1injp 的实质代码：

1. 在任务文件中写明参考文件、函数名、commit `5f19a0e` 与改动方式（移植/改写/仅参考）。
2. 在 `THIRD_PARTY_NOTICES.md` 增加条目：仓库 URL、文件路径、commit SHA、原版权行、MIT 许可证文本链接、改动摘要、访问日期。
3. 保留 `Copyright (c) 2026 satoru.net`；MIT 要求保留版权与许可声明，不得删除。
4. 移植后的代码必须：TypeScript 严格类型、无环境时间与 `Math.random`、遵守依赖边界、带单元测试、双语叙事完整。
5. 不把 1injp 的日本数值当作 LifeSim 的任何国家数据；即使算法相同，参数也必须另行来源。
