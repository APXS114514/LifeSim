## 目标

把世界银行 WDI 的中学入学与高中完成率转换成 `StatSeries`，进入五个国家包，替换 M3-012 需要的 D 级教育假设；**没有观测值的国家不造序列**。

## 背景

- 指标契约见 M3-003：`education-enrollment-secondary`（percent，WDI `SE.SEC.ENRR`）与 `education-completion-upper-secondary`（share，WDI `SE.SEC.CUAT.UP.ZS`）。
- 现有同类流程见 `data/scripts/worldbank/`（城镇比例）与 [M2-012](../tasks/M2-012.md)：原始数据只缓存到 `data/cache/`，派生 JSON 进 `packages/country-packs/data/<pack>/`。
- 朝鲜（KP）在世界银行教育指标上大概率没有观测值；**缺失必须表现为「没有序列」或 `null` + `missingReason`**，绝不能写 0，也不能用日本数据代替。
- 许可（Q4 已确认）：WDI 数据集页面**逐指标**核验，不能默认沿用已经核验的城镇比例来源 ID；每项指标单独登记来源、单位、时间覆盖、适用地域、许可与再分发条件。只登记事实与派生比例，不再分发原始 CSV。

## 实现要求

1. **抓取与缓存**：用世界银行 API（`https://api.worldbank.org/v2/country/CN;JP;KP;KR;RU/indicator/<code>?format=json&per_page=20000`）下载两个指标；原始响应存 `data/cache/`（已 gitignore），在 `inputs.json` 记录文件名、官方 URL、SHA-256、获取日期。
2. **转换**：脚本读取缓存，输出每个国家每个指标一个 `StatSeries`：`id: 'wdi/<PACK>/<indicator>'`、`geographyId: 'country:<PACK>'`、`sex: 'both'`、`points` 按年升序、`age: null`、`projected: false`；年份范围覆盖 1950—2026 中有观测的年份。
3. **空值**：WDI 的 `null` 观测不写成点（不是 `0`）；某国完全没有观测时**不生成序列文件**，在 `inputs.json` 与报告里写明「KP has no observations for <code>」。
4. **证据**：`evidence.grade: 'B'`、`sourceIds` 指向新登记来源、`modelVersion` 用国家包版本、`yearRange` 用实际观测年份区间、`methodId: 'wdi-<code>-raw'`。
5. **来源登记与许可**：每个指标在 `sources.json` 加一条（ID 形如 `worldbank-wdi:SE.SEC.ENRR`），`LICENSE_AUDIT.md` 记录数据集页面链接、CC BY 4.0 条款、`redistribution: 'allowed'` 与核验日期。**条款与既有 `SP.URB.TOTL.IN.ZS` 不一致或无法核验时停止**。
6. **接入国家包**：在五个包的 `series` 数组追加对应序列（没有观测的国家不加）；运行 `pnpm data:sources`、`pnpm data:coverage`、`pnpm check:data`。
7. **指纹**：只更新因新增序列而变化的数据指纹，提交说明写明「有意新增教育序列」。

## 可能的阻塞（遇到就停止并报告）

- WDI 对某指标返回的数据结构（`countryiso3code`、`value` 为 `null`）与现有脚本假设不符。
- 朝鲜完全没有观测，但维护者要求必须有数据（这需要 C/D 级推算规则，见 Q4/Q5，不是本任务能自行决定的）。
- `check:data` 要求每个指标在每个国家都有序列（若是，需要先改门禁，属高风险）。
