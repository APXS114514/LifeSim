| 项       | 内容                                                                |

| 风险     | 高（容差是产品与科学边界，需维护者确认）                            |
| 前置依赖 | M5-001；维护者决定 D10                                              |
| 涉及模块 | `docs/`（校准规格）、`qa/`（机器可读的指标与容差配置）              |

## 目标

GDD §9.3 与 M5 退出条件：校准指标要满足「事先声明的逐指标标准」。本任务在跑校准之前把指标、基准来源、分层与容差写下来，防止事后挑选。

## 已定的约束

1. 指标按国家/年份/年龄/城乡分层；每个指标写明基准数据集（只用已登记、已核验许可的来源）、证据等级与比较方法。
2. 容差逐指标设定，不一刀切；死亡率沿用 ADR-0007 已确认的口径（2 个百分点或 10%，取更宽者）。
3. 没有可用基准的指标标「未验证」，不得用游戏自身数据当基准。
4. 校准只说明总体分布相近，不声称个体因果准确（GDD §9.3）；这句话写进规格与生平报告的说明。

## 需要细化的内容

指标清单（候选：出生分布、年龄别死亡与生存曲线、预期寿命、教育完成率、劳动参与率与农业就业占比、婚育），每项的基准、分层、样本量与容差选项。

## 验收要点

机器可读配置能被 M5-003 读取；每个指标都有来源 ID、等级、容差或「未验证」；维护者签认记录。

## 可能的阻塞

D10 未决定；某国基准缺失（例如朝鲜），需要维护者决定是否缩小可验证范围并披露。
