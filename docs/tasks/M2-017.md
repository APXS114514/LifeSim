## 目标

写出中国大陆国家包中不含统计序列的部分，包括 1955 年新旧人民币兑换，以及重庆行政地位的两次变化（这是检验「同一地点、不同时期属于不同行政单位」的关键样例）。`series: []`。

## 背景（只需知道这些）

- 写法、来源规则、清单格式与 M2-014（`packs/jp.ts`）相同。
- `CN` 指中国大陆，不包括台湾、香港、澳门（GDD §11.3），名称写「中国大陆 / Mainland China」。
- 重庆：1949 年后先是中央直辖市，后并入四川省，1997 年又设为直辖市。两段「直辖市」时期用**两个不同的行政单位 ID**，地点 `place:cn-chongqing` 本身不变。
- 「待核实」的日期是预期值或需要确认的事件：来源证实的值不同、或来源互相矛盾（例如批准日与正式挂牌日不同）时，**停止并报告两个日期及来源**，由维护者决定。

### 来源

与 M2-014 相同的规则。行政区划变更优先引用中国政府网、全国人大、民政部等官方来源；人民币发行优先引用中国人民银行。
