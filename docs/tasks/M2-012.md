# M2-012：转换世界银行 WDI 城镇人口比例

| 项       | 内容                                                                                    |
| -------- | --------------------------------------------------------------------------------------- |
| 风险     | 高（真实数据）：PR 需维护者审查并加 `arch-approved` 标签                                |
| 前置依赖 | M2-001、M2-005、M2-009（且维护者已确认 `worldbank-wdi:SP.URB.TOTL.IN.ZS` 为 `allowed`） |
| 涉及模块 | `data/scripts/worldbank/`、`packages/country-packs/data/`                               |
| 预计改动 | 新增 3 个脚本文件、5 个数据文件                                                         |

## 目标

取出五个地区的城镇人口比例，写成 `StatSeries`。出生选择器用它决定出生在城镇还是农村（ADR-0005 §7）。

## 背景（只需知道这些）

- 指标 `SP.URB.TOTL.IN.ZS` 是城镇人口占总人口的**百分比**；本项目的单位是 `share`（0—1），所以要除以 100。
- 世界银行的国家代码：CN → `CHN`，JP → `JPN`，KP → `PRK`，KR → `KOR`，RU → `RUS`。
- 该指标通常从 1960 年开始；1950—1959 年的缺口由 DataRegistry 的声明规则处理（M2-007），**本任务不补任何年份**。
- API 返回的值可能为 `null`（未报告），必须写成缺失点并给出原因，不能写 0，也不能删掉这一年。
- 证据等级 B（该指标由国际机构根据各国数据估算）。

## 实现要求

### 获取原始数据（手动一次，记录在 `inputs.json`）

用 M2-009 记录的官方 API，一次取五个国家该指标的全部年份（JSON 格式、足够大的每页条数，确保只有一页），保存为 `data/cache/worldbank/urban-share.json`。在 `inputs.json` 记录 `id: 'urban-share'`、完整 URL、SHA-256、获取日期。若响应分页超过一页，报告阻塞。

### `urban-share.mjs`

```js
/**
 * @param {unknown} response  API 返回的 JSON（[元信息, 记录数组]）
 * @param {'CN'|'JP'|'KP'|'KR'|'RU'} packId
 */
export function toUrbanShareSeries(response, packId);  // => StatSeries
```

1. 响应必须是长度为 2 的数组，第二项是记录数组；否则抛错。
2. 每条记录中，按国家代码（ISO3，通常在 `countryiso3code` 字段）与指标 ID 选取；年份在 `date` 字段（字符串），值在 `value` 字段。字段名与此不同时停止并报告。
3. 对该国家：年份必须连续（从最早到最晚每年一条，不得重复）；否则抛错。
4. 点：`value` 为数字时取 `value / 100`；为 `null` 时写 `{ value: null, missingReason: 'not reported in World Bank WDI', … }`；`age: null`；`projected: false`；按年份**升序**（API 通常是降序）。
5. 如果最早或最晚的若干年全是 null，照样保留为缺失点（不截掉）。
6. 输出：
   - `id: 'wdi/<packId>/urban-share'`，`indicator: 'urban-share'`，`geographyId: 'country:<packId>'`，`unit: 'share'`，`ageBasis: 'none'`，`sex: 'both'`；
   - `evidence: { grade: 'B', sourceIds: ['worldbank-wdi:SP.URB.TOTL.IN.ZS'], modelVersion: 'wdi-<inputs.json 中的获取日期>', geographyId: 'country:<packId>', yearRange: [最早年, 最晚年], methodId: 'wdi-urban-share-percent-to-share' }`。
7. 返回前用 `StatSeriesSchema.parse` 校验。

命令行：`node data/scripts/worldbank/urban-share.mjs --input data/cache/worldbank/urban-share.json`，校验 SHA-256，写出五个文件（格式同 M2-010），打印每个地区的年份范围、缺失点数与 1960、2000 年的比例。

## 验收测试（必须新增，写在 `urban-share.test.ts`）

用**夹具响应**（注释标明「测试夹具，数值虚构」，包含降序年份、一个 null 值、一个其他国家的干扰记录）：

1. 百分比换算正确（例如 55.5 → 0.555），按年份升序，通过 `StatSeriesSchema`。
2. null 值成为带原因的缺失点，**不是 0**，也没有被删除。
3. 年份不连续或重复时抛错；响应结构不对时抛错。
4. 其他国家的记录被忽略。
5. 若仓库里已有 `packages/country-packs/data/*/wdi-urban-share.json`：每个都通过 `StatSeriesSchema`，非 null 值都在 [0, 1]。
