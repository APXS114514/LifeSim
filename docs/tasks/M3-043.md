## 目标

GDD 决定 11：健康、幸福、经济、知识、关系等可见指标「由后台细状态派生」。现在的角色状态只有学历、就业、疾病、余额与关系，幸福与人际几乎没有可变的底层状态，指标会长期不动，通用事件（M3-042）也没有可以作用的地方。

## 已定的约束

1. 只加 M3-042 与 M4-016 真正需要的最小字段（候选：压力、社交联系、技能/兴趣、近期重大经历的记忆），每个字段写明取值范围、谁可以改、如何派生成指标；具体字段由 ADR-0010 确定。
2. 新字段在出生时确定性初始化；如需随机数，追加在出生随机流末尾，不改变已有抽样位置（主角已有结果不变）。
3. 提升 `SYSTEMS_VERSION`；`SNAPSHOT_SCHEMA_VERSION` 是否提升由 ADR-0010 决定；旧存档按 Q9 非破坏性处理。
4. 指标不入库：可见指标仍是纯函数派生（M4-016）。

## 验收要点

schema 正反例测试；出生初始化确定性；旧快照被拒绝时走非破坏性路径；黄金指纹变化说明；性能测量。

## 可能的阻塞

ADR-0010 未采纳；字段需求在 M3-042 细化中变化（先回到 ADR 修订）。
