# M4-012：国家数据包按需加载

| 项       | 内容                                                                 |
| -------- | -------------------------------------------------------------------- |
| 风险     | 高（国家包入口与构建产物）：走 `task/M4-012-lazy-packs` 分支         |
| 前置依赖 | M4-006（界面）、M3 数据全部就位                                      |
| 涉及模块 | `packages/country-packs`、`packages/real-world`、`apps/web`          |
| 预计改动 | 重构国家包入口为按包动态加载；修改 real-world 初始化；构建分析；测试 |

## 目标

避免五国完整统计同时阻塞首屏：首屏只加载应用外壳与所选国家包；切换国家或导入其他国家存档时按需加载；离线缓存与 M4-011 配合。

## 背景

- 现状：`PACKS` 一次性导入五个包（含 ~1.5 MB × 5 的 qx JSON），构建产物单个 4.1 MB chunk（gzip 690 KB）。
- GDD §11.1：国家数据包应尽可能按需加载。
- 约束：确定性、数据指纹、`createPackRegistry` 的查询逻辑不变；拆包不能改变任何数值。
- 依赖方向：`apps/web` 可以依赖 `country-packs` 与 `real-world`；拆包实现放在这两个包内。

- `packages/country-packs/src/{packs/index.ts,registry.ts,select-birth.ts}`

## 实现要求

1. **按包加载**：`loadPack(packId)` 返回该包的 `CountryPack` 与它的序列；内部用动态 `import()`，打包器为每个包生成独立 chunk。
2. **查询**：`createPackRegistry(packs)` 允许只传入已加载的包；未知包查询返回 `missing` 并带原因，不抛意外错误。
3. **选择器**：随机出生需要按出生数加权——随机国家时必须先加载**全部**包的出生数（这是唯一需要全量数据的场景）；实现上允许只加载 births 序列（若拆得更细），否则在随机出生时显示加载全量数据的进度。
4. **首屏**：指定国家出生时只加载一个包；构建分析记录首屏 chunk 大小（目标：gzip 后显著小于当前 690 KB，具体数字记录）。
5. **确定性**：拆包前后同一 request 的事实指纹相同；数据指纹（`DATA_FINGERPRINTS`）不变。
6. **离线**：已加载的包 chunk 可被 Service Worker 缓存（M4-011）。
7. **错误**：加载失败（网络/离线未缓存）显示双语提示并允许重试；不得静默使用其他国家数据。

## 验收测试

1. 单包加载：初始化 JP 只请求 JP 的 chunk（在 E2E 里断言 request 列表，或在单元测试里用注入 loader 断言调用）。
2. 数值不变：拆包前后 JP 1978 / CN 1960 / RU 1980 的人生事实指纹相同（黄金测试或固定快照）。
3. 随机出生：需要全量出生数时有明确加载路径与进度；失败时提示。
4. 未加载包查询：返回 `missing` 与原因。
5. 构建：记录 chunk 列表与首屏 gzip 大小；没有把五国数据同时塞回首屏 chunk。
6. 现有 `acceptance.test.ts`、`registry.test.ts`、`select-birth.test.ts` 全部通过。

## 实施记录（2026-10-21）

- 保留默认 Node/CLI 同步入口；新增 `browser` 条件入口，仅包含轻量地理/历史元数据、姓名与已加载包。`loadPack` 动态导入独立国家 chunk，随机国家明确加载五包并报告进度。
- 地理元数据从原包原样抽出；统计 JSON、规则、出生抽样顺序、数据和事实黄金值均未修改。已有包注册表允许 partial；网页加载第二个国家后真实数据索引会重建。
- 开局和读档等待所需包。下载失败不会把有效存档标成损坏。Chromium 会记住失败的 ESM 导入，因此重试先在 sessionStorage 保留开局请求，再刷新继续；读档重试直接刷新恢复原存档。
- 文档前置状态偏差：M4-006 尚未登记完成，但现有可玩界面已经具备出生、自动存档和读档接口，本任务按这些实际接口集成；未宣称 M4-006 完成。
