## 目标

建立国家包的格式（schema）、校验函数与「某地某日属于哪个政治实体 / 行政单位、叫什么、用哪版货币」的解析函数。**本任务不写任何真实国家的数据**（五个国家分别在 M2-014 至 M2-018），用测试夹具验证。

## 背景（只需知道这些）

- 一个国家包包含：清单、地理（政治实体、行政单位、地点、地点归属）、货币、历史锚点、断点、统计序列（GDD §5，ADR-0005 §1）。
- 国家包覆盖期从 1950-01-01 开始；有效期是半开区间（M2-002）。
- 依赖方向已登记：`@lifesim/country-packs` 可依赖 `content-schema`、`data-registry`、`simulation-core`（本任务只需要前两个）。
- 「其他城镇地区」「其他农村地区」两个人口池地点每个国家各一个（GDD §4.3）。

## 实现要求

### 包

`name: '@lifesim/country-packs'`，结构同 `packages/narrative`；依赖 `@lifesim/content-schema`、`@lifesim/data-registry`（`workspace:*`）与 `zod`（与其他包相同的精确版本）。`README.md` 写明：本包含五个首发地区的数据包；派生数据只能来自 `data/sources.json` 中可再分发的来源；许可与来源见 `data/LICENSE_AUDIT.md`、`data/SOURCES.md`（各包清单的 `licenseManifestPath` 指向本 README）。

### `schema.ts`

```ts
export const CurrencyDefinitionSchema = z.strictObject({
  code: z.string().regex(/^[A-Z]{3}$/),
  initialVersion: z.number().int().positive(),
  /** 每个币制版本的显示名，键为版本号字符串（"1"、"2"…）。 */
  versionNames: z.record(z.string().regex(/^[1-9]\d*$/), LocalizedNameSchema),
});

export const CountryPackSchema = z.strictObject({
  manifest: CountryPackManifestSchema,
  geographyId: EntityIdSchema,
  names: LocalizedNameSchema,
  politicalEntities: z.array(PoliticalEntitySchema).min(1),
  adminUnits: z.array(AdminUnitSchema).min(1),
  places: z.array(PlaceSchema).min(1),
  placeAssignments: z.array(PlaceAssignmentSchema).min(1),
  currency: CurrencyDefinitionSchema,
  anchors: z.array(HistoricalAnchorSchema),
  breakpoints: z.array(BreakpointSchema),
  series: z.array(StatSeriesSchema),
});
export type CountryPack = z.infer<typeof CountryPackSchema>;
export const PACK_COVERAGE_START = '1950-01-01';
```

### `validate.ts`

`export function validateCountryPack(pack: unknown): string[]`，返回问题列表（空数组 = 合格）。先做 `CountryPackSchema.safeParse`，失败则把 zod 问题转成字符串返回、不再继续。之后逐条检查（每条问题文本都包含相关 ID）：

| #   | 规则                                                                                                                                                                                                                         |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `manifest.packId` ∈ `BIRTH_REGION_IDS`；`manifest.role === 'birth'`；`manifest.validFrom === PACK_COVERAGE_START`；`geographyId === 'country:' + packId`                                                                     |
| 2   | 政治实体、行政单位、地点的 ID 在三者合起来的范围内唯一                                                                                                                                                                       |
| 3   | 恰好一个 `kind: 'other-urban'` 地点、恰好一个 `kind: 'other-rural'` 地点                                                                                                                                                     |
| 4   | 每个归属的 `placeId` 都是已定义的地点                                                                                                                                                                                        |
| 5   | 每个地点的归属在 `[PACK_COVERAGE_START, ∞)` 上无重叠、无空隙（用 `findOverlaps`、`findGaps`）                                                                                                                                |
| 6   | 每个归属引用的行政单位与政治实体都存在，且其有效期覆盖该归属在 `[PACK_COVERAGE_START, ∞)` 内的整个区间                                                                                                                       |
| 7   | 每个地点的名称时段在 `[PACK_COVERAGE_START, ∞)` 上无重叠、无空隙                                                                                                                                                             |
| 8   | 每个锚点的 `regionIds` 包含 `packId`；锚点类型只能是 `redenomination` 或 `polity-change`                                                                                                                                     |
| 9   | 币制重定值按日期排序后形成链条：第一个的 `fromVersion` 等于 `currency.initialVersion`，之后每个的 `fromVersion` 等于前一个的 `toVersion`；`currencyCode` 等于 `currency.code`；`versionNames` 包含初始版本与每个 `toVersion` |
| 10  | 政体更替锚点：`fromEntityId`、`toEntityId` 都存在；前者的 `validTo` 与后者的 `validFrom` 都等于锚点日期                                                                                                                      |
| 11  | 被归属引用、且 `validTo` 落在覆盖期内的政治实体，必须有一个以它为 `fromEntityId`、日期等于其 `validTo` 的政体更替锚点                                                                                                        |
| 12  | 断点的每个 `geographyId` 是本包的 `geographyId` 或本包地点的 ID                                                                                                                                                              |
| 13  | 序列的 `geographyId` 是本包的 `geographyId` 或本包地点的 ID；同一（指标、地理）不重复；序列 `id` 包含 `/<packId>/`                                                                                                           |

### `resolve.ts`

```ts
export function assignmentAt(pack: CountryPack, placeId: string, date: ISODate): PlaceAssignment;
export function politicalEntityAt(
  pack: CountryPack,
  placeId: string,
  date: ISODate,
): PoliticalEntity;
export function adminUnitAt(pack: CountryPack, placeId: string, date: ISODate): AdminUnit;
export function placeNameAt(pack: CountryPack, placeId: string, date: ISODate): LocalizedName;
export function currencyAt(pack: CountryPack, date: ISODate): CurrencyVersion;
export function poolPlace(pack: CountryPack, settlement: 'urban' | 'rural'): Place;
```

- 日期早于 `PACK_COVERAGE_START` 时抛 `RangeError`；找不到地点或当天没有有效记录时抛 `Error`（消息含地点 ID 与日期）。
- `currencyAt`：从 `initialVersion` 开始，依次应用 `at <= date` 的币制重定值（**重定值当天新币已生效**）。
- `poolPlace`：返回对应的 `other-urban` / `other-rural` 地点。

## 验收测试（必须新增）

在测试文件中构造一个**夹具国家包**（`packId: 'RU'`，所有名称以「测试」/`Test` 开头，注释标明「测试夹具，非真实历史」）：两个政治实体在 `2000-01-01` 更替并有对应锚点；一个城市在 `1990-06-01` 改名；一个城市的行政归属在 `1980-01-01` 变化；货币有两次重定值（1→2、2→3）。

`validate.test.ts`：

1. 夹具包通过（返回 `[]`）。
2. 规则 1—13 每条各构造一个违反样例，断言返回的问题中包含相关 ID（共 13 条，可用 `it.each`）。

`resolve.test.ts`：

1. 更替前一天、当天、后一天的政治实体分别正确。
2. 改名前一天与当天的名称分别正确；行政归属变化前后正确。
3. 两次重定值的前一天、当天：`currencyAt` 返回正确版本。
4. `1949-12-31` 抛 `RangeError`；未知地点抛错。
5. `poolPlace` 返回两个人口池地点。
