# M3-027：朝鲜特色事件

| 项       | 内容                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| 风险     | 高（国家内容 + 来源 + 状态后果）：走 `task/M3-027-kp-events` 分支                |
| 前置依赖 | M3-023（事件目录框架）、M3-012（教育规则）                                       |
| 涉及模块 | `packages/systems`、`data/`、`packages/real-world`                               |
| 预计改动 | 新增 `events/kp.ts` + 测试；修改 `module.ts`、`narrative.ts`、来源登记；黄金指纹 |

## 目标

用 M3-023 的事件目录为朝鲜补 3—5 条**有真实状态后果**的年代事件，覆盖教育、职业/经济、家庭或迁移中的至少三类；每条事件都有可核查来源与中英双语叙事。

## 背景

- 朝鲜的资料极少，且很多来源是韩国官方教育/研究机构或脱北者证词，不是朝鲜官方数据（M2 已登记这一局限）。
- GDD §3.1 要求朝鲜体现「制度化生活条件和极低频、受严格时空资格约束的脱北相关事件」，并要求尊重当事人处境、不能戏谑化。
- 本任务必须**极度保守**：宁可只有 2—3 条事件，也不能编造统计、日期或政策细节。所有无法核实的数值标 C/D 并说明。
- 不得把韩国或日本的社会制度套用到朝鲜；不得使用未核实的「官方数据」措辞。

## 必读文件

- `packages/systems/src/events/catalog.ts`、`events/cn.ts`（M3-023 的框架与首国实现）
- `packages/systems/src/{education.ts,career.ts,finance.ts}`（当前状态字段）
- `docs/REFERENCE_REUSE.md` §4.1 R3、§5
- `data/sources.json`、`data/LICENSE_AUDIT.md`
- GDD §3.1、§7

## 允许修改

- 新增 `packages/systems/src/events/kp.ts` 与 `events/kp.test.ts`
- `packages/systems/src/module.ts`：装配该国事件
- `packages/systems/src/narrative.ts`：事件模板与枚举
- `data/sources.json`、`data/SOURCES.md`（生成）、`data/LICENSE_AUDIT.md`
- `packages/synthetic-world/src/golden.ts`：确认差异合理后更新

## 禁止修改

`simulation-core`、`content-schema`、`country-packs` 数据（除非某事件必须新增锚点，那要先报告）、`events/catalog.ts` 的语义（只允许修 bug）、`docs/adr`、`qa/`、`scripts/check-*`、`apps/`。

## 实现要求

1. 事件 ID 形如 `kp.<slug>`，年代窗口与资格必须逐条给出；每条事件的事实类型 = 事件 ID。
2. 至少 3 条、最多 5 条；三条不同类别（教育、职业/经济、家庭/迁移）各至少一条。
3. 每条事件**必须改变至少一个状态字段**（学历、就业、账户、居住地、健康、关系），不能只发事实；不允许「只加背景文案」。
4. 每条事件的事实带 `evidenceIds`，来源在 `data/sources.json` 登记（许可、`redistribution`、`verifiedAt`）；`LICENSE_AUDIT.md` 写明只引用事实。
5. 双语模板：键 = 事件 ID；占位符只来自 `details`；不允许在模板里断言未经核实的统计数字。
6. 叙事尊重当事人处境，不戏谑化困难经历（GDD §3.1）。
7. 不引入该国以外的事件；不把日本的社会制度套用到别国。

## 候选事件（必须逐条核实来源；核不到就换或报告）

| 候选 ID                   | 年代      | 类别      | 后果                                                                                                  |
| ------------------------- | --------- | --------- | ----------------------------------------------------------------------------------------------------- |
| `kp.school-system`        | 1970s 起  | 教育      | 学制与升学资格（只在有可靠来源时）                                                                    |
| `kp.hardship-1990s`       | 1994—1998 | 家庭/健康 | 食物与收入冲击（措辞必须中性；来源必须注明为外部研究）                                                |
| `kp.currency-reform-2009` | 2009      | 经济      | 储蓄大幅缩水（币制锚点已在国家包；事件只做个人后果）                                                  |
| `kp.defection`            | 1990s 起  | 迁移      | **默认不做**：需要 Q10 明确授权与内容分级；若做，必须极低频、严格资格、严肃处理，且不提供现实行动指引 |

默认交付：只做能核实的 2—3 条；宁可少，不可编。

## 验收测试

1. 每条事件：窗口内固定 seed 至少发生一次；窗口外一次都不发生。
2. 资格：不满足条件的状态不会触发（逐条断言）。
3. 后果：每条事件至少一个状态字段变化（逐条断言具体字段与新值）。
4. 覆盖：该国全部事件都有 zh-Hans 与 en 模板、都有来源、都有 `applies/chance/run`。
5. 预算与确定性：同一年最多 2 条目录事件；同 seed 两次运行一致。
6. 现有测试与不变量全部通过；黄金指纹变化已解释。

## 需要维护者先确认

- Q10：内容分级、脱北事件是否纳入、事件文本审校流程。
- 朝鲜事件的来源全部为外部研究时，证据等级与界面披露方式。

## 可能的阻塞（遇到就停止并报告）

- 关键史实来源不可核实或与任务描述不符。
- 需要的状态字段尚不存在（依赖 M3-012/013/014/021）。
- 事件触发的年代与数据包锚点冲突（例如币制改革年份）。
