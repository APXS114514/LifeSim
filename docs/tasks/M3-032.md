# M3-032：地区旗帜资源与许可登记

| 项       | 内容                                                                 |
| -------- | -------------------------------------------------------------------- |
| 风险     | 中（新增静态素材 + 许可登记；不改规则）                              |
| 前置依赖 | M3-031（按政体 ID/日期解析标签）                                     |
| 涉及模块 | `apps/web/public`、`apps/web/src`、`docs/`、`THIRD_PARTY_NOTICES.md` |
| 预计改动 | 新增 6—10 个 SVG 旗帜 + 1 个映射模块 + 测试；更新许可记录            |

## 目标

在出生地区列表与角色卡中显示真实旗帜：现代国家用现行国旗，历史政体用对应历史旗帜（例如苏联）；按政体 ID + 生效日期选择，不用国家代码硬编码。旗帜作为辅助识别，不喧宾夺主。

## 背景

- 现有政体：`polity:cn-prc`、`polity:jp-japan`、`polity:kp-dprk`、`polity:kr-rok`、`polity:ru-russian-federation`、`polity:ussr`（1950—1991 的 RU 地点）。
- 出生年份覆盖 1950—2026，因此需要至少 6 面旗帜；未来新增加盟共和国/后继国家时，映射表按 `polityId` 扩展，不写国家分支。
- **许可红线**：不得从 1injp 或其他项目复制旗帜；不得使用来源不明的地图/截图。旗帜是官方符号，多数为公有领域，但必须逐文件核验来源与许可。
- 参考项目评估已明确：1injp 的地图/字体/素材许可未清理，不得复制（[REFERENCE_REUSE](../REFERENCE_REUSE.md) 第 7 节）。

## 实现要求

1. **来源策略（二选一，优先 A）**：
   - A. 依据官方规格（颜色、比例、几何）自行绘制 SVG；在 `docs/FLAG_SOURCES.md` 记录依据的官方/权威规格链接与绘制日期。几何简单的旗帜（中、日、俄、韩、朝）可行；苏联旗帜的徽记较复杂，若自绘失真则改用 B。
   - B. 从 Wikimedia Commons 选用标注为公有领域（PD）或 CC0 的 SVG；逐文件核验许可页，记录文件页 URL、作者、许可、获取日期、SHA-256，并保留许可要求的署名。
   - **任一方式都不得使用 CC BY-NC、未标注许可或来源不明的文件。**
2. **资源规范**：
   - 每面旗帜统一 viewBox（建议 3:2 或官方比例），不嵌入位图，不引用外部 URL；
   - 白底/浅色旗帜（日本、韩国、朝鲜）加 1px 中性描边容器，保证浅色背景可见；
   - 文件命名 = polity ID 去掉 `polity:` 前缀，例如 `ussr.svg`、`cn-prc.svg`。
3. **映射**：`flags.ts` 导出 `flagForPolity(polityId)`，未登记时返回 null；组件渲染中性占位（不猜测、不用现代国旗顶替历史政体）。
4. **UI**：
   - 出生设置地区列表：每个地区项左侧 20×14 左右的旗帜 chip，`aria-hidden`（文字仍是可访问名称）；
   - 角色卡：地区标记旁显示当前政体旗帜（按 M3-031 的日期解析）；
   - 时间线/总结：不强制加旗帜，避免视觉噪声；如加，只用于「出生国」一处。
   - 旗帜不改变布局宽度：容器固定尺寸，长名称由 M3-031 的两行布局处理。
5. **验证资源**：测试逐个读取注册的 SVG，断言以 `<svg` 开头、不含 `http://`/`https://` 引用、宽高比在 1.2—1.8 之间；每个文件在 `docs/FLAG_SOURCES.md` 有一行记录。
6. **不做**：不在本任务新增政体/加盟共和国数据；不做旗帜动画；不把旗帜用于政治表态。

## 验收测试

1. 映射完整性：遍历五国包中所有可能出现在 1950—2026 的 polity ID，断言 `flagForPolity` 返回非 null 或明确的 fallback 记录；历史政体 `polity:ussr` 返回苏联旗帜，`polity:ru-russian-federation` 返回俄罗斯联邦旗帜。
2. 资源：所有注册 SVG 通过格式/外部引用/宽高比断言；`docs/FLAG_SOURCES.md` 覆盖全部文件。
3. UI：出生页五地区各显示旗帜；RU 1980 角色卡显示苏联旗帜，1992 年后显示俄罗斯联邦旗帜（依赖 M3-031/M3-001）。
4. 可读性：浅色旗帜有描边且与背景对比可辨；320/390 视口无横向溢出；旗帜不挤压长名称。
5. 现有 E2E 与单测通过；没有新增网络请求（旗帜是本地静态资源）。

## 可能的阻塞（遇到就停止并报告）

- 无法确认某面旗帜的再分发许可 → 不使用该素材，改用自绘或留占位；在报告中说明。
- 苏联徽记自绘无法保证辨识度且没有合规来源 → 暂用纯红底 + 简化星形并明确标注「简化旗帜」，等待维护者确认是否可接受。
- 需要修改 `CountryPack` 结构才能表达旗帜 → 停止；本任务只做 UI 映射。
