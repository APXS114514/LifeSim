# M2-020：把统计序列接入五个国家包，并建立国家包数据查询入口

| 项       | 内容                                                                     |
| -------- | ------------------------------------------------------------------------ |
| 风险     | 中（接线 + 数据指纹）：路径属于高风险清单，PR 需维护者加 `arch-approved` |
| 前置依赖 | M2-008、M2-010、M2-011、M2-012、M2-014、M2-015、M2-016、M2-017、M2-018   |
| 涉及模块 | `packages/country-packs`                                                 |
| 预计改动 | 修改 6 个文件，新增 3 个文件                                             |

## 目标

1. 让五个国家包通过 JSON 导入，带上各自的三个序列（出生数、生命表 qx、城镇比例）。
2. 提供 `createPackRegistry()`：用全部国家包的序列、断点和「地点 → 国家」的上级关系建立一个 `DataRegistry`。
3. 用数据指纹锁定已接入的数据，防止数据文件被悄悄修改。

## 背景（只需知道这些）

- 数据文件已由 M2-010、M2-011、M2-012 生成：`packages/country-packs/data/<packId>/{wpp2024-births,wpp2024-qx,wdi-urban-share}.json`。
- JSON 导入写法：`import births from '../../data/CN/wpp2024-births.json' with { type: 'json' };`（相对路径从 `src/packs/` 出发，仍在本包目录内，符合依赖边界）。导入后用 `StatSeriesSchema.parse` 校验，不要用类型断言绕过校验。
- `DataRegistry` 的构造参数见 `packages/data-registry/src/registry.ts`（M2-006 至 M2-008）。

## 必读文件

- `packages/country-packs/src/packs/{cn,jp,kp,kr,ru}.ts`、`packs/index.ts`
- `packages/data-registry/src/registry.ts`
- `packages/simulation-core/src/random.ts`（`fingerprint`）、`json.ts`（`canonicalJson`）

## 允许修改

- `packages/country-packs/src/packs/{cn,jp,kp,kr,ru}.ts`：只把 `series: []` 改为导入的三个序列
- `packages/country-packs/src/packs/index.ts`：`PACKS` 改为完整的 `Record<BirthRegionId, CountryPack>`
- 新增 `packages/country-packs/src/registry.ts`、`src/registry.test.ts`
- 新增 `packages/country-packs/src/data-golden.ts`
- `packages/country-packs/src/index.ts`：导出 `registry.ts`
- `packages/country-packs/package.json`：加入 `@lifesim/simulation-core` 依赖（`workspace:*`）；`pnpm-lock.yaml`

## 禁止修改

数据文件本身、数据脚本，以及其他所有文件。

## 实现要求

1. 每个包的 `series` 依次为：出生数、qx、城镇比例（各自 `StatSeriesSchema.parse(导入的 JSON)`）。
2. `packs/index.ts`：`export const PACKS: Record<BirthRegionId, CountryPack> = { CN: CN_PACK, JP: JP_PACK, KP: KP_PACK, KR: KR_PACK, RU: RU_PACK };`
3. `registry.ts`：

   ```ts
   /** 用全部国家包建立数据查询入口；地点的上级是所属国家（ADR-0005 §4 第 3 步）。 */
   export function createPackRegistry(
     packs: Readonly<Record<BirthRegionId, CountryPack>> = PACKS,
   ): DataRegistry;
   ```

   `parents`：每个包的每个地点 ID → 该包的 `geographyId`。`breakpoints`：所有包的断点拼在一起。

4. `data-golden.ts`（**高风险文件**，文件顶部注释说明：只有数据有意更新并经维护者审查后才能改）：

   ```ts
   export const DATA_FINGERPRINTS: Record<string, string> = {
     // 序列 id → fingerprint(canonicalJson(序列))
   };
   ```

   15 个条目（5 个地区 × 3 个序列），值用当前数据计算后写入。

## 验收测试（必须新增，写在 `src/registry.test.ts`）

1. 每个包都通过 `validateCountryPack`，且恰好有 3 个序列，指标分别为 `births`、`life-table-qx`、`urban-share`。
2. 每个序列的指纹等于 `DATA_FINGERPRINTS` 中的值，且 `DATA_FINGERPRINTS` 恰好有 15 个条目、每个都对应一个已接入的序列。
3. `createPackRegistry()` 对五个地区：1950 年与 2026 年的出生数为 `found`（2026 年 `projected: true`）；2000 年 0 岁与 100 岁的 qx 为 `found`（100 岁值为 1）；城镇比例在该序列最早的非 null 年份为 `exact`。
4. 城镇比例在 1955 年：若该序列最早非 null 年份是 1960，则结果为 `hold-first-observed`、等级 D；在 1958 年为 `fallback-neighbor-year`、等级 C。（若实际最早年份不是 1960，按 ADR-0005 的规则写出相应期望，并在报告中说明。）
5. 用地点 ID 查询（例如 `place:ru-moscow` 的 1990 年出生数）走 `fallback-parent-geography`，值等于国家的值。
6. 任何查询结果里都不出现用 0 代替缺失：对五个地区 1950—2026 年逐年查询出生数，全部为 `found` 且值 > 0。
