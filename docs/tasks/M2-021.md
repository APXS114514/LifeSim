## 目标

实现「选出生」：按玩家的选择或随机规则，确定出生地区、日期、地点、城乡、出生时的行政单位、政治实体与货币版本。结果是一个结构化的 `BirthContext`，供 M3 的人生规则使用。**本任务不修改 `systems`，不把结果接入人生模拟。**

## 背景（只需知道这些，规则已由维护者确定，不得更改）

- GDD §4.3 与 ADR-0005 §7：
  - 随机年份：1950—2026 等概率。
  - 随机地区：只在五个首发地区之间，按该年出生数加权，P = Bᵢ / ΣBⱼ；任何一个地区该年的出生数查不到时**报错**，不跳过、不当 0。
  - 地区内：按该年城镇比例决定城镇 / 农村，落到对应的人口池地点（M2 不按城市加权）。
  - 日期：该年内每天等概率。
- 随机流：`deriveStream(seed, 'birth-selection')`，抽样顺序固定（见下）；**玩家手动指定的项也照常抽样**，这样改变一项选择不会让其他抽样错位（与 M1 出生事件同一约定）。
- `RandomStream` 的方法：`int(n)` 返回 [0, n) 整数，`next()` 返回 [0, 1)。

## 实现要求

```ts
export interface BirthRequest {
  seed: string;
  region: BirthRegionId | 'random';
  year: number | 'random';
  /** 精确出生日期（测试与将来的界面使用）；给出时必须落在 year 指定的年份内。 */
  birthDate?: ISODate;
}

export interface BirthContext {
  packId: BirthRegionId;
  birthDate: ISODate;
  placeId: string;
  settlement: 'urban' | 'rural';
  adminUnitId: string;
  politicalEntityId: string;
  currency: CurrencyVersion;
  provenance: {
    /** 随机地区时各地区的出生数权重；指定地区时为 null。 */
    regionWeights: Record<BirthRegionId, number> | null;
    urbanShare: { value: number; method: LookupMethod; grade: EvidenceGrade; sourceYear: number };
  };
}

export function selectBirth(
  request: BirthRequest,
  packs: Readonly<Record<BirthRegionId, CountryPack>> = PACKS,
  registry?: DataRegistry,
): BirthContext;
```

`registry` 省略时：若 `packs === PACKS`，使用模块内缓存的 `createPackRegistry(PACKS)`（第一次调用时创建，之后复用，因为建立索引要校验约 7.7 万个数据点）；否则调用 `createPackRegistry(packs)`。

步骤（抽样顺序固定，每一步无论是否用到都抽）：

1. `yearDraw = random.int(77)`；年份 = 指定值，或 `1950 + yearDraw`。指定的年份必须满足 `isSelectableBirthYear`，否则抛 `RangeError`；给了 `birthDate` 时，它的年份必须等于该年份，否则抛 `RangeError`。
2. `regionDraw = random.next()`；地区为随机时：按 `BIRTH_REGION_IDS` 的顺序查询每个地区 `country:<id>` 该年的出生数，任一为 `missing` 就抛 `Error`（消息含地区、年份与原因）；令 `total = Σ 权重`，选第一个满足 `regionDraw * total < 累计权重` 的地区。
3. `urbanDraw = random.next()`；查询所选地区该年的 `urban-share`；`missing` 时抛 `Error`；`settlement = urbanDraw < share ? 'urban' : 'rural'`。
4. `dayDraw = random.int(该年天数)`；出生日期 = 指定的 `birthDate`，或该年 1 月 1 日加 `dayDraw` 天。
5. 地点 = `poolPlace(pack, settlement)`；`adminUnitId`、`politicalEntityId` 用出生日期从地点归属解析；`currency = currencyAt(pack, 出生日期)`。
6. `provenance` 如实填写（城镇比例的 `method`、证据等级、`sourceYear` 取自查询结果）。

## 验收测试（必须新增，写在 `select-birth.test.ts`）

用**夹具国家包与夹具数据**（在测试文件中构造，注释标明「测试夹具，数值虚构」；出生数权重设为 CN 50、JP 20、KP 10、KR 15、RU 5，城镇比例设为 0.6）：

1. 同一请求两次调用，结果完全相同。
2. 权重：对 20,000 个不同种子随机选地区，各地区频率与 Bᵢ/ΣB 的差都小于 0.01。
3. 年份：对 20,000 个种子随机选年份，1950—2026 每一年都出现，且最多与最少出现次数之比小于 1.5。
4. 城镇比例：20,000 个种子中城镇占比与 0.6 的差小于 0.01。
5. 抽样对齐：同一种子下，「地区随机且选中 X」与「地区指定为 X」得到相同的出生日期与城乡。
6. 任一地区该年出生数缺失时，随机地区抛错；指定地区时只查询该地区，不受其他地区缺失影响。
7. 指定 1949 年、2027 年、或 `birthDate` 与年份不符，抛 `RangeError`。

用**真实国家包**（`PACKS`）：

8. `selectBirth({ seed: 's', region: 'RU', year: 1991, birthDate: '1991-12-25' })` 的政治实体为 `polity:ussr`；`birthDate: '1991-12-26'` 为 `polity:ru-russian-federation`；两者的地点相同（同一种子）。
9. `selectBirth({ seed: 's', region: 'KR', year: 1962, birthDate: '1962-06-09' })` 的货币版本为 2，`'1962-06-10'` 为 3。
