# M5-006：存档回归语料与导入导出样本（骨架）

| 项       | 内容                                                       |
| -------- | ---------------------------------------------------------- |
| 风险     | 中                                                         |
| 前置依赖 | M4-003（导入导出）；M4-002（存档校验与迁移）               |

| 执行者   | 细化与实施交给执行 Agent                                   |

## 目标

GDD §14.1 把「存档数据丢失、不可恢复」列为 P0；发布清单要求「导入导出往返样本」。建立一组固定的存档语料，覆盖各版本、中途暂停在决定上、已结束的人生、损坏与被篡改的文件，作为每次发布的回归测试。

## 已定的约束

1. 沿用 Q9 = 非破坏性：不兼容或损坏的存档保留原文、可导出、提示原因，绝不静默删除。
2. 语料文件由脚本生成并记录生成它的提交；不手写伪造的存档。
3. 当前版本的存档往返后继续推进，与不中断推进逐字节相同。

## 需要细化的内容

语料清单与生成脚本、旧版本存档的处理期望、篡改与截断的用例、E2E 导入导出流程。

## 验收要点

每个语料都有期望结果（可恢复 / 不兼容并保留 / 损坏并保留）且测试通过；导入导出往返样本随发布候选报告保存。

## 可能的阻塞

M4-002 的迁移策略与 Q9 冲突。
