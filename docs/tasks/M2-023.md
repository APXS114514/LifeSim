# M2-023：数据覆盖率矩阵

| 项       | 内容                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------ |
| 风险     | 低（只读数据生成文档）；改动 `data/scripts/` 与 CI 属于高风险路径，PR 需维护者加 `arch-approved` |
| 前置依赖 | M2-020                                                                                           |
| 涉及模块 | `data/scripts/`、`docs/data/`、根 `package.json`、`.github/workflows/ci.yml`                     |
| 预计改动 | 新增 3 个文件，修改 2 个文件                                                                     |

## 目标

生成 `docs/data/COVERAGE.md`：每个地区、每个指标覆盖了哪些年份、证据等级、预测年份、缺失年份。这是阶段 2 任务要求的「数据覆盖率矩阵及真正的数据缺口」，并在 CI 中检查它与数据同步。

## 背景（只需知道这些）

- 数据在 `PACKS` 中（`packages/country-packs/src/packs/index.ts`）；脚本可以直接导入 `../../packages/country-packs/src/index.ts`。
- 缺口必须如实列出，不能因为有回退规则就把缺口写成「已覆盖」。

## 必读文件

- `packages/country-packs/src/packs/index.ts`、`src/schema.ts`
- `scripts/check-licenses.mjs`（「检查模式 / `--write` 模式」的结构参考）

## 允许修改

- 新增 `data/scripts/coverage.mjs`、`data/scripts/coverage.test.ts`
- 新增 `docs/data/COVERAGE.md`（由脚本生成）
- `package.json`：加入 `"data:coverage": "node data/scripts/coverage.mjs --write"` 与 `"check:coverage": "node data/scripts/coverage.mjs"`，并把 `pnpm check:coverage` 加进 `verify`（放在 `pnpm check:data` 之后）
- `.github/workflows/ci.yml`：在 `pnpm check:data` 之后加 `- run: pnpm check:coverage`

## 禁止修改

其他所有文件。

## 实现要求

导出纯函数 `renderCoverage(packs)`，返回完整的 Markdown 文本：

1. 开头：标题「数据覆盖率」，说明「本文件由 `pnpm data:coverage` 生成，请勿手改」，以及证据等级的含义链接到 `docs/DATA_POLICY.md`。
2. 一张汇总表，每个地区 × 指标一行：`地区 | 指标 | 序列 ID | 来源 | 等级 | 年份范围 | 预测年份 | 年龄范围 | 缺失点数 | 缺失年份`。
   - 年份范围：最早与最晚的点；预测年份：`projected: true` 的最早—最晚，没有则 `—`；年龄范围：`ageBasis` 为 `none` 时写 `—`。
   - 缺失年份：值为 null 的年份，连续的合并为区间（例如 `1950—1959`）；没有则 `—`。
3. 「已知缺口」一节：列出每个指标在 1950—2026 出生年份范围内**没有精确值**的年份区间，并注明会走哪条回退规则（按 ADR-0005 §4 推断：相邻年份 / 首个观测值前延 / 无法回退）。
4. 地区按 `BIRTH_REGION_IDS` 顺序，指标按 births、life-table-qx、urban-share 顺序；输出以单个换行结尾。

命令行：默认比较生成结果与 `docs/data/COVERAGE.md`，不同则提示运行 `pnpm data:coverage` 并以退出码 1 结束；`--write` 写入文件。

## 验收测试（必须新增，写在 `data/scripts/coverage.test.ts`）

用夹具包（注释标明夹具）：

1. 有预测年份与无预测年份的序列分别正确显示。
2. 缺失年份合并为区间（例如 1950、1951、1952、1955 → `1950—1952, 1955`）。
3. 1950—1959 无数据的城镇比例在「已知缺口」中列为 `1950—1957`（首个观测值前延）与 `1958—1959`（相邻年份）——前提是夹具最早年份为 1960。
4. 对真实 `PACKS` 运行 `renderCoverage`，结果与仓库中的 `docs/data/COVERAGE.md` 完全一致。
