## 目标

实现符合历史条件的国际迁移：移居到另一个国家、取得或保留国籍、跨国工作的资格重认定；**迁居不等于改国籍**；迁入目的地数据不足时用「只支持迁入」的轻量包并明确披露。

## 背景

- GDD §5：迁移引擎记录申请/决定/实际搬迁/身份审批/家庭变化/就业资格重认定等阶段；不能把国籍变更与地理迁移等同；跨国目的地可以用只支持迁入的轻量地区包运行。
- GDD §3.1：中国大陆「符合特定身份条件的赴台湾特殊历史路径」（需要在任务中讨论是否纳入；**默认不做**，因为涉及主权表述与数据，报告给维护者）。
- 现状：`CountryPackManifest` 有 `role: 'birth' | 'inbound'`（M2 已定义），但没有迁入包。
- Q6 未决：v0.1 是否只允许在五国之间迁移。默认按「五国之间 + 不新建第三国包」执行，需维护者确认。
- 朝鲜半岛早期南向北迁移的史实范围、资格与后果设计见 [M3-033](M3-033.md) 与 [设计文档](../history/korea-northbound-migration.md)；本任务负责提供跨境迁移机制，不自行决定敏感历史内容。
- 苏联/俄罗斯：1991 年后在境外（例如波罗的海）的居民国籍问题不在五国范围内；不得自行扩展。

## 实现要求

1. **阶段**：申请 → 决定 → 搬迁 → 身份审批 → 就业资格重认定，每一步产生事实；任意阶段可以失败（拒签、撤回）。
2. **国籍**：默认保留原国籍；取得目的地国籍必须另有事实与资格（居住年限、婚姻、归化政策），且需要来源或 D 级标注；**不得**因为搬家自动改国籍。
3. **目的地**：只能迁移到已登记的国家包；目标包为 `role: 'inbound'` 时，使用其地理/币制/数据子集，并在界面与事实里标注「简化地区」。
4. **资格**：按年代与政治条件（例如冷战时期的出境限制、朝鲜的出境限制）决定是否可行；没有可靠来源时用 D 级条件并报告，**尤其朝鲜必须极低频且严格资格**（Q10）。
5. **就业**：外国学历/资格不自动等同本地执业资格（GDD §8.2）；迁移后由 `career.ts` 重新判定。
6. **家庭**：家人是否随迁、是否保留国籍分别决定；不得强制全家迁移。
7. **币制**：迁移后账户按目的地币制新建；原账户按规则换算或保留，必须在任务报告里写清口径（不得丢失金额）。

## 验收测试

1. **迁居不改国籍**：CN→JP 迁移后 `currentResidenceId` 在 JP，`citizenshipIds` 仍是 CN。
2. **归化**：满足条件（如居住年限）后可申请并取得新国籍，需要事实链；不满足时选项不可用。
3. **资格失败**：不满足出境/入境条件时，事件不发生或申请被拒，状态不变。
4. **轻量包**（若实现）：迁入后能继续推进到死亡，币制、地理、生命表都能解析；数据缺口被标注。
5. **苏联**：1991 年前出生的 RU 角色迁往其他国家后，1991 年锚点不得改变其居住地（仅按 M3-001 规则改政治实体）。
6. **家庭**：至少一局出现「部分家人未随迁」。
7. **确定性**：同 seed 两次运行一致；快照往返一致。
