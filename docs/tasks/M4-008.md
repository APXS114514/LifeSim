## 目标

手机（竖屏）上完整可玩：单列时间线、顶部可折叠状态、底部控制条、关系与详情用抽屉打开；无横向滚动、触控目标足够大、支持键盘与屏幕阅读器。

## 背景

- GDD §10：手机单列时间线，顶部可折叠状态，底部控制条或抽屉显示关系/决策/详情；所有关键操作支持点击、触摸与键盘，不依赖悬停。
- QA_GATE 的 E2E 已包含手机视口冒烟；M4 要扩展到完整流程。
- 现有 CSS 已有移动断点；本任务把它们系统化，不做全站视觉重做。

## 实现要求

1. **断点**：≥1024px 三栏（M4-006）；<1024px 单栏；<640px 时面板改为全屏抽屉。
2. **顶部状态**：可折叠摘要（年龄、地区、健康/经济概览）；折叠状态持久化到界面状态（不写存档）。
3. **底部控制条**：时间控制（M4-005）固定可见、不遮挡内容；≤ 44px 触控目标。
4. **抽屉**：关系、统计、决定详情以 sheet 打开；Esc/下滑/点击遮罩关闭；焦点陷阱与返回焦点。
5. **无横向滚动**：所有视口宽度 320—1024px 断言 `document.documentElement.scrollWidth <= clientWidth`。
6. **字体与颜色**：只用系统字体；对比度满足基本可读性（不引入外部资源）。
7. **i18n**：抽屉标题、按钮、空状态双语。

## 验收测试

1. Playwright（390×844、768×1024、1280×800）：完整流程（出生 → 推进 → 决定 → 死亡总结）可完成。
2. 无横向滚动：三种视口断言。
3. 抽屉：打开/关闭、Esc、焦点返回。
4. 折叠：状态在页面内保持，刷新后回到默认展开（或按设计持久化到 localStorage，需说明）。
5. 触控：控制按钮 bounding box 高度 ≥ 44px。
6. 双语：移动端文案两种语言都存在。
