# M3-009：RegionModel 扩展实现（数据查询接入）

| 项       | 内容                                                                                  |

## 目标

按 ADR-0007 扩展 `RegionModel`，让规则能按国家、年份、城乡、家庭背景查询教育、劳动力、价格与卫生数据；合成地区与真实国家包都必须实现新接口，**现有 M1 行为保持不变**（黄金指纹不变）。

## 背景

- 现状：`RegionModel` 有 13 个查询 + `RegionRules` + `RegionEffects`；真实实现把教育/劳动/价格/卫生全写成 ADR-0006 的常数。
- ADR-0007 决定接口形态与缺失回退；本任务只做实现，不再做设计决定。ADR 里没有写到的部分保持现状。
- 合成地区（`packages/synthetic-world/src/region.ts`）是黄金指纹的基准：它必须实现新成员并返回与现在**完全相同**的数值，否则说明接口设计把行为改了。

## 实现要求

1. **接口**：严格按 ADR 的签名实现（方法名、参数、返回类型、可选性）。不要顺手加 ADR 没写的成员。
2. **真实实现**：每个查询用 `DataRegistry.lookup`（或 ADR 指定的批量接口），显式传 `allowScenario` 仅限 ADR 允许的指标；缺失时按 ADR 的回退表返回，**不得抛错除非 ADR 规定必须抛**（例如生命表缺失）。
3. **证据**：新增数据表的 `EvidenceMeta` 必须来自序列本身的证据，不得伪造 B 级。
4. **合成地区**：新成员返回与现有常数完全相同的值；若 ADR 把某个旧成员改名或合并，合成地区也要同步，且黄金指纹保持不变。
5. **规则侧**：只替换取数来源，不改变概率公式与判定顺序；任何一个旧常数被替换后必须能在 ADR 的回退表里找到依据。
6. **性能**：构造 `RegionModel` 时不预读全部序列；单次查询不得遍历 7 万个点（必要时在 `real-world` 里缓存按（指标, 地理）的索引）。

## 验收测试

1. **黄金指纹不变**：`synthetic-world/life.test.ts` 的 `GOLDEN_LIFE` 断言通过（不许改指纹）。
2. **真实查询**：JP 1978 的中学入学率、KR 1997 的 CPI、RU 1990 的劳动参与率等，返回值与 `DataRegistry.lookup` 的结果一致；证据等级随回退规则降级（至少 2 个断言）。
3. **缺失路径**：构造一个没有某指标的夹具地区（测试夹具），断言按 ADR 规定回退/抛错，且错误信息含指标与年份。
4. **确定性**：同一 seed + 五国各跑一次完整人生，两次运行的规范事实指纹相同。
5. **性能**：`pnpm bench --lives 500` 的 `p50` 不超过 M3 前的 3 倍（记录两组数字）；超过时报告原因而不是放宽断言。
