## 目标

在精确查询失败时，按 ADR-0005 §4 的顺序回退，并在结果里如实写明用了哪条规则、证据等级降到多少。回退规则**只有下面列出的这几条**，不得新增、调整顺序或放宽参数。

## 背景（只需知道这些）

- 规则来源：`docs/adr/0005-m2-data-architecture.md` 第 4、5 节（本文已完整转写，不需要另读 GDD）。
- 回退是为了在小缺口上保持可玩，同时让缺口可见：所以回退结果的证据等级只降不升，方法写进 `evidence.methodId`。

## 实现要求

`lookup(query)` 依次尝试，第一个成功的返回：

**第 1 步 精确值**：M2-006 的逻辑。若点存在但 `value` 为 null，视为缺口，继续往下。

**第 2 步 相邻年份**：在同一序列、同一年龄中，找 `|y − 目标年| ∈ {1, 2}` 且 `value` 非 null 的点，排除「跨越断点」的候选；取距离最近的，距离相同取**较早**的年份。

- 跨越断点：存在断点 b（`geographyIds` 含查询地理，`indicators` 含查询指标，b 为 `date` 的年份），使 `min(y, 目标年) < b ≤ max(y, 目标年)`。
- 结果：`method: 'fallback-neighbor-year'`，`sourceYear = y`，`projected` 取该点的标记。

**第 3 步 上级地理**：`options.parents[geographyId]` 存在时，对上级地理做**第 1 步**（只做精确值，不递归、不再回退）。

- 结果：`method: 'fallback-parent-geography'`，`sourceGeographyId` = 上级地理。

**第 4 步 声明规则 `hold-first-observed`**：只适用于 `urban-share`。目标年早于该序列最早的非 null 年份 f，且 `f − 目标年 ≤ 10`，并且目标年与 f 之间不跨越断点（同第 2 步的定义）时，取 f 的值。

- 结果：`method: 'hold-first-observed'`，`sourceYear = f`，`projected: false`。

**第 5 步 缺失**：返回 `{ status: 'missing', reason }`，reason 依次说明各步为何失败（至少包含查询的指标、地理、年份；若第 1 步遇到的是 null 点，包含该点的 `missingReason`）。

**证据等级**（第 2、3、4 步都要做，返回原证据的副本并修改）：

| 原等级 | 第 2、3 步后 | 第 4 步后 |
| ------ | ------------ | --------- |
| A、B   | C            | D         |
| C      | C            | D         |
| D      | D            | D         |

同时把 `evidence.methodId` 设为对应的方法名（`fallback-neighbor-year`、`fallback-parent-geography`、`hold-first-observed`）。精确命中时证据保持原样。

## 验收测试（必须新增，写在 `fallback.test.ts`）

夹具（注释标明「测试夹具，数值虚构」）：

- `test/AA/births`，地理 `country:AA`，B 级，年份 1950、1951、1953、1954、1958，值依次 10、11、13、14、18；1952 为 null 点（`missingReason: 'fixture gap 1952'`）。
- `test/AA/urban-share`，地理 `country:AA`，B 级，1960—1962 值 0.30、0.31、0.32。
- `test/AA/births` 的上级测试：地点 `place:aa-city` 没有序列，`parents: { 'place:aa-city': 'country:AA' }`。
- 断点 `bp-1956`：`geographyIds: ['country:AA']`、`date: '1956-01-01'`、`indicators: ['births']`。

| #   | 查询                              | 期望                                                                 |
| --- | --------------------------------- | -------------------------------------------------------------------- |
| 1   | births 1951                       | exact，值 11，等级 B                                                 |
| 2   | births 1952                       | neighbor-year，取 1951（与 1953 同距离取较早），值 11，等级 C        |
| 3   | births 1956                       | neighbor-year，取 1958，值 18（1954 跨越断点被排除，见表下说明）     |
| 4   | births 1955                       | 候选 1953、1954（不跨越），1957 不存在；取 1954，值 14               |
| 5   | births 1957                       | 1955、1956 无点；1958（距 1，min=1957 < 1956？否 → 不跨越）→ 取 1958 |
| 6   | births 1946                       | 1948、1947 无点，返回 missing                                        |
| 7   | births 2000，地理 `place:aa-city` | 第 2 步无序列，第 3 步父级精确查 2000 无点 → missing                 |
| 8   | births 1950，地理 `place:aa-city` | parent-geography，值 10，等级 C，`sourceGeographyId: 'country:AA'`   |
| 9   | urban-share 1955                  | hold-first-observed，值 0.30，等级 D，`sourceYear: 1960`             |
| 10  | urban-share 1949                  | 1960 − 1949 = 11 > 10 → missing                                      |
| 11  | urban-share 1958                  | neighbor-year 优先（1960 距 2），值 0.30，等级 C                     |
| 12  | births 1952 且原等级为 D 的序列   | 等级仍为 D                                                           |
| 13  | 任何回退结果                      | `evidence.methodId` 等于方法名，原序列的证据未被修改                 |

另加一个 fast-check 性质测试：对夹具 births 序列，随机查询 1940—1970 的任意年份，结果要么 `missing`，要么 `value` 等于序列中某个非 null 点的值，且 `|sourceYear − 查询年| ≤ 2`；永远不出现 0。

注意第 3 行：断点年 b = 1956，候选 1954 与目标 1956：min = 1954 < 1956 ≤ max = 1956，属于跨越，排除；候选 1958 与目标 1956：min = 1956，1956 < 1956 不成立，不跨越。请严格按公式实现，**测试期望以公式为准**；若你认为公式本身有问题，报告而不要修改。
