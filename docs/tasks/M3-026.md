# M3-026：俄罗斯特色事件

| 项       | 内容                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| 风险     | 高（国家内容 + 来源 + 状态后果）：走 `task/M3-026-ru-events` 分支                |
| 前置依赖 | M3-023（事件目录框架）、M3-012（教育规则）                                       |
| 涉及模块 | `packages/systems`、`data/`、`packages/real-world`                               |
| 预计改动 | 新增 `events/ru.ts` + 测试；修改 `module.ts`、`narrative.ts`、来源登记；黄金指纹 |

## 目标

用 M3-023 的事件目录为俄罗斯（含苏联时期）补 3—5 条**有真实状态后果**的年代事件，覆盖教育、职业/经济、家庭或迁移中的至少三类；每条事件都有可核查来源与中英双语叙事。

## 背景

- 俄罗斯/苏联：1961 年币制改革（已在国家包里）、1980 年莫斯科奥运会、1985 年改革（perestroika）、1991 年解体（M3-001 已实现）、1992 年价格自由化与转型衰退、1998 年 8 月违约、2008—2009 年危机。
- 制度变化与币制、政体锚点必须与 M2 的国家包一致：事件不得与锚点日期冲突（例如 1991-12-26 之前不能出现「俄罗斯联邦」）。
- 本任务只做个人层面的后果（职业、收入、消费、迁移），宏观更替由锚点负责。

- `packages/systems/src/events/catalog.ts`、`events/cn.ts`（M3-023 的框架与首国实现）
- `packages/systems/src/{education.ts,career.ts,finance.ts}`（当前状态字段）
- `docs/REFERENCE_REUSE.md` §4.1 R3、§5

- `packages/systems/src/narrative.ts`：事件模板与枚举

## 禁止修改

`simulation-core`、`content-schema`、`country-packs` 数据（除非某事件必须新增锚点，那要先报告）、`events/catalog.ts` 的语义（只允许修 bug）、`docs/adr`、`qa/`、`scripts/check-*`、`apps/`。

## 实现要求

1. 事件 ID 形如 `ru.<slug>`，年代窗口与资格必须逐条给出；每条事件的事实类型 = 事件 ID。
2. 至少 3 条、最多 5 条；三条不同类别（教育、职业/经济、家庭/迁移）各至少一条。
3. 每条事件**必须改变至少一个状态字段**（学历、就业、账户、居住地、健康、关系），不能只发事实；不允许「只加背景文案」。
4. 每条事件的事实带 `evidenceIds`，来源在 `data/sources.json` 登记（许可、`redistribution`、`verifiedAt`）；`LICENSE_AUDIT.md` 写明只引用事实。
5. 双语模板：键 = 事件 ID；占位符只来自 `details`；不允许在模板里断言未经核实的统计数字。
6. 叙事尊重当事人处境，不戏谑化困难经历（GDD §3.1）。
7. 不引入该国以外的事件；不把日本的社会制度套用到别国。

## 候选事件（必须逐条核实来源；核不到就换或报告）

| 候选 ID                 | 年代      | 类别      | 后果                                     |
| ----------------------- | --------- | --------- | ---------------------------------------- |
| `ru.perestroika-reform` | 1985—1991 | 职业/经济 | 就业结构变化、收入不确定性上升           |
| `ru.shock-therapy`      | 1992—1995 | 经济/家庭 | 储蓄贬值、消费下降、失业                 |
| `ru.1998-default`       | 1998      | 经济      | 收入与储蓄冲击（与 1998 币制重定值区分） |
| `ru.2008-crisis`        | 2008—2009 | 经济      | 就业与收入冲击                           |
| `ru.moscow-olympics`    | 1980      | 迁移/经济 | 城市机会变化（可选）                     |

注意：1998 年的「违约」与「币制重定值」是两件事，叙事必须区分；币制换算由 M1 的锚点负责，事件不能重复换算金额。

## 验收测试

1. 每条事件：窗口内固定 seed 至少发生一次；窗口外一次都不发生。
2. 资格：不满足条件的状态不会触发（逐条断言）。
3. 后果：每条事件至少一个状态字段变化（逐条断言具体字段与新值）。
4. 覆盖：该国全部事件都有 zh-Hans 与 en 模板、都有来源、都有 `applies/chance/run`。
5. 预算与确定性：同一年最多 2 条目录事件；同 seed 两次运行一致。
6. 现有测试与不变量全部通过；黄金指纹变化已解释。

## 可能的阻塞（遇到就停止并报告）

- 关键史实来源不可核实或与任务描述不符。
- 需要的状态字段尚不存在（依赖 M3-012/013/014/021）。
- 事件触发的年代与数据包锚点冲突（例如币制改革年份）。
