# M3-041 年度重点实施细化（乘数范围已确认）

这是对已采纳 D14 / ADR-0008 的实施细化。用户已在本次会话明确采纳本表；目前尚未启用新规则，接下来按本表实施。

## 选项与资格

每个主角生日安排 `choice.yearly-focus`，`background: true`，不暂停且不消耗随机数。均衡、健康、家庭人际、休闲始终可选；学习在 6 岁起可选；工作在法定工作年龄起、未退休且非在校时可选。未预设时按人生原则确定，预设不合格则沿用 ADR-0008 的软回退。

## 集中设计表

全部为 D 级设计假设。先读取地区的基线概率，再乘本表，最终夹取到 0—1。乘数统一限制在 **0.85—1.15**，不得直接作用于死亡概率。

| 重点     | 入学/升学 | 求职 | 失业 | 发病 | 年度压力增量 | 年度社交联系增量 |
| -------- | --------- | ---- | ---- | ---- | ------------ | ---------------- |
| 均衡     | 1.00      | 1.00 | 1.00 | 1.00 | 0            | 0                |
| 学习     | 1.15      | 0.95 | 1.00 | 1.00 | +0.01        | 0                |
| 工作     | 0.95      | 1.15 | 0.85 | 1.10 | +0.03        | 0                |
| 健康     | 1.00      | 0.95 | 1.00 | 0.85 | -0.02        | 0                |
| 家庭人际 | 1.00      | 0.95 | 1.00 | 1.00 | -0.01        | +0.03            |
| 休闲     | 0.95      | 0.95 | 1.00 | 0.95 | -0.03        | +0.01            |

压力与社交联系更新只修改 ADR-0010 B 已批准的字段，每次夹取到 0—1。治疗的可用性、费用、资格与玩家选择保持现有语义；没有治疗成功率时不凭空增加抽样。M3-042 v1 的原型发生概率保留其集中目录的固定值，避免破坏已推导的覆盖率与披露；原型仍能读取并改变共享细状态。

## 持久化与排程

不再增加 CharacterState 字段。生日仅安排重点决定与下一个生日；重点结算后安排当年的原有系统事件，将该年重点作为 occurrence payload 传递。升学与治疗等同日连锁继续传递此载荷，NPC 没有主角重点载荷时使用均衡乘数。

当前重点由 `decision.made` 事实派生，未来预设继续保存在 ADR-0008 的 `schedulerState.presets`；不建立并行权威状态。重点决定保留完整审计事实，时间线可将其呈现为年度标题。界面说明“对下一年生效”，已处理年份不可追改。

## 验证

- 全部选项与年龄/状态资格、纯函数与无随机消耗；软预设回退及存档往返。
- 固定种子集合中学习的升学率高于休闲，健康的发病率低于工作；所有概率有界。
- 重点只影响主角，不能更改 NPC 概率或直接改死亡风险；细状态始终在范围内。
- 相同动作序列在逐年、快进与单事件推进中逐字节相同；重点载荷在同日连锁与恢复后保留。
- 黄金样本有意变化时先提供逐项差异，由维护者确认后更新；不改旧测试来迁就实现。
