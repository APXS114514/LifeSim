## 目标

实现国内迁居：从农村到城市、城市之间、行政区划变更；居住地改变但**出生地不变**；迁居影响生活成本、就业机会与健康；迁居是可选择的行动，不是随机瞬移。

## 背景

- 现状：`CharacterState` 有 `birthPlaceId` 与 `currentResidenceId`，但两者永远相同；`finance.ts` 用 `origin.settlement`（出生时的城乡）计算生活费，迁移后会出错。
- GDD §5：地理至少分离 `placeId`、`adminUnitId`、`politicalEntityId`、`birthPlaceId`、`currentResidenceId`、`citizenshipIds`；区划合并/拆分用历史映射表，不能覆盖出生地址。
- GDD §4.2：迁居与政体变化是不同事件；M3-001 已保证 1991 年不自动搬家。
- 城市与省级数据（Q11）未定：本任务默认只使用国家包现有的代表性城市与「其他城镇/农村」人口池；城市权重缺失时用 D 级权重并标注。

## 实现要求

1. **迁居事件**：成年后可选择迁居；玩家/原则可以决定；资格依赖（是否有目的地、是否有钱、是否健康、是否有家庭牵绊）。
2. **状态变更**：只改 `currentResidenceId`（以及必要时 `health`/`finance` 的派生值）；`birthPlaceId` 永不变；`politicalEntityId` 与 `citizenshipIds` 不因国内迁居改变。
3. **城乡与成本**：生活成本与就业机会按**当前**居住地的城乡属性计算，不再用 `origin.settlement`；迁移后下一个生日结算立即生效。
4. **行政区划**：如果国家包里有区划变更（例如重庆 1997），迁居后的行政区划按当日解析（`adminUnitAt`），不得覆盖历史。
5. **家庭**：Tier1 家人是否随迁由关系与原则决定（不得强制全体搬家）；不随迁时关系 `coResident` 变为 false。
6. **事实**：迁居事实带 `fromPlaceId`、`toPlaceId`、原因、成本与证据；叙事双语。
7. **不自动**：政体更替、币制改革、经济衰退都不直接改动居住地。

## 验收测试

1. 农村出生者迁居城市后，生活成本按城市计算，`birthPlaceId` 不变，`politicalEntityId` 不变。
2. 资金不足时无法迁居（选项 `eligible: false` 或事件不发生），且有原因。
3. 家庭：至少一局中出现「家人未随迁」与 `coResident: false`。
4. 行政区划：重庆相关夹具在 1997 年前后解析到不同行政单位，迁居历史不被覆盖。
5. 无关事件：1991 年俄罗斯角色不因政体更替改变 `currentResidenceId`（M3-001 回归）。
6. 确定性：同 seed 两次运行一致；快照往返一致。
7. `pnpm life:real --region CN --year 1960 --all` 的输出里能看到迁居事实（若该 seed 不发生，换 seed 并记录）。
