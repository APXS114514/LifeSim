## 目标

把「一条慢性病 + 治疗/不治疗」升级为疾病持续状态机：发病 → 症状 → 诊断 → 治疗 → 康复或长期影响；疾病影响就业、收入、家庭支出与关系；医疗可及性随国家与年代变化。

## 背景

- 现状：`HealthConditionSchema` 只有 `id/onset/treated/factId`，全部疾病共用一个 `'chronic'` id；治疗是二选一，且 1980 年前不可获得（五国共用）。
- GDD §8.3：疾病是持续状态，能影响现金流和就业；医疗条件因时代/地区而异；死亡风险必须与生命表统一校准（M3-016）。
- 疾病发病率**没有**可再分发的五国历史序列（WDI 没有；IHME GBD 是 CC BY-NC-SA，不能用于本项目）——因此本任务必须使用**明确的 D 级年代化假设表**，并在 ADR-0007 的回退表里登记，不得伪装成统计。
- 医疗可及性可以用 M3-006 的自付比例与人均支出构造 C 级指标（方法写进 ADR）。

## 实现要求

1. **契约**：`HealthConditionSchema` 扩展为
   - `id`：疾病种类（稳定 ID，例如 `condition:chronic-respiratory`）；
   - `onset`、`diagnosedOn: ISODate | null`、`stage: 'onset' | 'diagnosed' | 'treated' | 'recovered' | 'chronic'`；
   - `treatmentStartedOn: ISODate | null`、`severity: 0..1`、`factId`；
   - 跨字段规则：`diagnosedOn !== null` ⇔ `stage !== 'onset'`；`treatmentStartedOn !== null` ⇔ `stage ∈ {'treated','recovered','chronic'}`。
2. **状态机**：发病后先进入 `onset`，下一次健康检查才可能诊断（概率受医疗可及性影响）；诊断后才出现治疗选项；治疗后按疾病种类进入 `recovered` 或 `chronic`；`chronic` 持续影响就业与支出。
3. **影响**：疾病（未治疗或慢性）通过 `RegionEffects` 影响求职、失业、死亡乘数与年度治疗支出；所有影响都必须引用疾病事实作为原因。
4. **医疗可及性**：按（国家, 年份）决定治疗可得年份、自付比例与质量；不得五国共用 1980 这个常数。
5. **数据**：发病率表是 D 级；可及性指标来自 M3-006（B 级）时标 B/C；每个数值带证据 ID 与 `methodId`。
6. **不重复**：疾病只改变死亡乘数，绝不单独再抽一次死亡（M3-016 会锁定这一点）。

## 验收测试

1. 状态机路径：构造固定 seed 使某角色发病，断言 `onset → diagnosed → treated` 的日期顺序与事实顺序；没有诊断就不能治疗（选项 `eligible: false` 且原因 `not-diagnosed`）。
2. 康复与慢性：两种结局都有测试覆盖；`recovered` 后不再产生该病的年度费用。
3. 就业影响：慢性病患者的失业概率高于同等条件健康者（固定 seed 批量比较，给出比例）。
4. 医疗可及性：1950 年与 2000 年的治疗可得性不同（至少 2 个国家断言），不可得时选项说明原因。
5. 契约一致性：fast-check 生成随机健康状态，schema 跨字段规则无违规。
6. 黄金指纹变化需报告并解释。

## 完成定义

- 疾病是持续状态，诊断、治疗、康复/慢性化可追溯；医疗条件随国家与年代变化。
- 发病率明确标为 D 级，来源与方法写入 ADR-0007 的回退表。
