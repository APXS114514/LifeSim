# M4-015：站点图标（favicon / app icon）

| 项       | 内容                                                            |
| -------- | --------------------------------------------------------------- |
| 风险     | 低（只新增静态资源与 HTML 链接；不改模拟、存档、规则）          |
| 前置依赖 | 无（可早于 M3 验收；属于界面外壳）                              |
| 涉及模块 | `apps/web/public`、`apps/web/index.html`、`apps/web/e2e`        |
| 预计改动 | 新增 1 个 SVG + 3 个 PNG；修改 `index.html`；新增 1 个 E2E spec |

## 目标

把页头左侧的品牌图形正式用作站点图标：提供 SVG favicon、浏览器兼容 PNG、Apple touch icon 与后续 PWA 可复用的 192/512 图标；标题、favicon 与页头保持同一视觉识别。

## 背景

- 现状：`apps/web/index.html` 的 favicon 是空 `data:,`，没有图标；页头品牌图形是内联 SVG（`App.tsx` 的 `.brand-mark`）。
- 图形语义：圆环 + 一条起伏的人生曲线 + 三个节点；不得改变含义，只做 favicon 所需的构图整理与导出。
- 全部资源为项目原创（几何图形），不使用第三方图片或字体；不需要 `THIRD_PARTY_NOTICES.md` 条目。
- PWA 尚未开始（M4-011）；本任务只提供图标文件，不新增 manifest、不注册 Service Worker。

## 必读文件

- `apps/web/index.html`
- `apps/web/src/app/App.tsx`（`.brand-mark` 的内联 SVG）
- `apps/web/src/styles.css`（品牌色 `--accent`、`--paper`、`--line-strong`）
- `apps/web/e2e/smoke.spec.ts`（E2E 写法）
- `apps/web/playwright.config.ts`

## 允许修改

- 新增 `apps/web/public/favicon.svg`
- 新增 `apps/web/public/favicon-32.png`、`apps/web/public/apple-touch-icon.png`、`apps/web/public/icon-192.png`、`apps/web/public/icon-512.png`
- `apps/web/index.html`
- 新增 `apps/web/e2e/appearance.spec.ts`
- `apps/web/src/app/App.tsx`：只允许加注释说明页头图形与 favicon 同源，不改几何

## 禁止修改

`packages/*`、模拟与存档逻辑、`docs/adr`、`docs/GDD.md`、`qa/`、`scripts/check-*`、根 `package.json`。不得引入第三方图标库或外部字体。

## 实现要求

1. **SVG favicon**（64×64 viewBox）：
   - 圆角方形底（`#f4efe4` 一类纸色）+ 1.5—2px 描边（`#c4b9a2`）；
   - 与页头相同的曲线路径与三个节点，颜色用品牌棕 `#8a4b2a`；
   - 不含文字，保证 16×16 下仍可辨认；图形居中，四周留 10% 安全边。
2. **PNG 导出**：32×32、180×180（Apple）、192×192、512×512；从同一 SVG 渲染，圆角外透明。
3. **index.html**：用 Vite 的 `%BASE_URL%` 前缀，避免 GitHub Pages 子路径失效：
   - `<link rel="icon" href="%BASE_URL%favicon.svg" type="image/svg+xml" />`
   - `<link rel="icon" href="%BASE_URL%favicon-32.png" sizes="32x32" type="image/png" />`
   - `<link rel="apple-touch-icon" href="%BASE_URL%apple-touch-icon.png" />`
   - 保留 `<meta name="viewport">` 与 `<meta name="color-scheme">`；移除空 favicon。
4. **一致性**：页头内联 SVG 与 favicon 的曲线与节点位置保持同一比例；在 `App.tsx` 加注释指向 `public/favicon.svg`。
5. **不新增 PWA manifest**；图标文件供 M4-011 使用。
6. **资源体积**：单个 PNG ≤ 40 KB，SVG ≤ 4 KB。

## 验收测试（`e2e/appearance.spec.ts`）

1. 页面加载后存在 `link[rel="icon"][type="image/svg+xml"]`，`href` 以 `favicon.svg` 结尾。
2. `request.get('/favicon.svg')` 返回 200，content-type 含 `svg`，body 以 `<svg` 开头。
3. `request.get('/favicon-32.png')` 与 `/apple-touch-icon.png` 返回 200 且 content-type 含 `png`。
4. 页头 `.brand-mark svg` 仍可见（视觉识别一致）。
5. 无控制台错误。

## 可能的阻塞（遇到就停止并报告）

- Vite 不替换 `%BASE_URL%`（退回到相对路径并在报告说明）。
- PNG 渲染在无浏览器环境不可用（需报告实际限制，不要用未验证的替代品伪装完成）。
