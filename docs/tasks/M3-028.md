## 目标

用可重复的测试证明 M3 的五项退出条件（GDD §13）：五地基础完整人生可通关；关键事件互相产生后果；所有事件通过状态不变量；死亡原因无重复风险抽样；同种子与不同推进方式结果一致。产出可供维护者复核的真实数字。

## 背景

- QA_GATE 的 M3 行要求：资产负债守恒、亲子关系无自环等性质测试；死亡风险不重复抽样；五地出生到死亡的端到端因果测试。
- 现有测试是分模块的；本任务补**跨系统**的验收层。
- 本任务不允许为了让测试通过而放宽断言；发现问题就报告并指向对应任务。

## 实现要求

测试文件至少包含以下 8 组：

1. **五国通关**：CN/JP/KP/KR/RU 各 3 个出生年（1950、1980、2010）× 固定 seed，全部从出生跑到死亡；断言有出生事实、死亡事实、孩子/父母/婚姻中至少一个家庭事实（若该国规则允许）。
2. **推进方式等价**：对每国 1 个人生，比较「一次 advanceTo 到死亡」「逐年推进」「每次一个事件」的事实规范 JSON 指纹，三者相同。
3. **同种子可复现**：同 seed 两次运行指纹相同；不同 seed 至少产生 2 种不同结局（死亡年龄或事实数不同）。
4. **状态不变量**：每局结束后重新用 schema 校验快照与事实日志（`checkJournalInvariants(complete: true)`），并断言不变量检查函数返回空数组。
5. **死亡终止**：死亡日期之后没有任何以主角为 actor 的事实；队列无剩余主角事件。
6. **NPC 一致性**：死亡 NPC 之后没有新事实；未成年人没有被雇佣；没有负年龄。
7. **因果链**：至少断言 5 条跨系统因果（例如衰退 → 失业 → 负债；疾病 → 治疗支出 → 贫困；迁居 → 收入变化；婚姻 → 子女；政体更替 → 国籍变更），每条检查 `causeEventIds` 链。
8. **存档往返**：每国 1 局在中途存档、恢复、继续，事实与不中断一致；文件编码解码往返一致。

另外（若实现批量报告脚本）：9. **批量报告**：五国各 100 局，输出死亡年龄分布、平均事实数、平均存档字节、每国 p50/p99 耗时；写入 `qa/m3-report.json`（只读产物）并在报告里贴关键数字。

## 完成定义

- 8 组测试全部存在并通过（或如实报告失败并指向根因任务）。
- 报告里贴出真实数字：五国死亡年龄中位数、平均事实数、p50/p99、失败用例（若有）。
- 没有修改黄金指纹、没有放宽既有断言。

## 可能的阻塞（遇到就停止并报告）

- 某国因为数据缺口无法跑到死亡 → 报告缺口与对应任务。
- 推进方式不等价（内核 bug 或新事件排程问题）→ 报告具体事实差异，不要改测试迁就。
- 性能超出 GDD 预算（桌面 5 秒）→ 报告并建议在 M3-029 的已知限制里披露。
