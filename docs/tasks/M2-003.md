# M2-003：历史锚点增加「政体更替」类型

| 项       | 内容                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 风险     | 高（公共契约 + 系统规则文件）：PR 需维护者审查并加 `arch-approved` 标签 |
| 前置依赖 | 无                                                                      |
| 涉及模块 | `packages/content-schema`、`packages/systems`（两处类型收窄）           |
| 预计改动 | 修改 4 个文件                                                           |

## 目标

在 `HistoricalAnchorSchema` 中加入 `polity-change`（例如 1991-12-26 苏联 → 俄罗斯联邦）。M2 只需要能**描述**它；把它作用到在世角色是 M3 的工作。

## 背景（只需知道这些）

- 现有锚点类型：`redenomination`（币制重定值）与 `economy-phase`（经济阶段），定义在 `packages/content-schema/src/anchor.ts`。
- `packages/systems` 有两处代码用 `if (anchor.kind === 'economy-phase') … else …` 区分类型，新增类型后 TypeScript 会在 `else` 分支报错，需要改成显式判断。
- 合成地区没有政体更替锚点，所以合成人生的结果**必须完全不变**（黄金指纹不变）。

## 必读文件

- `packages/content-schema/src/anchor.ts`
- `packages/content-schema/src/money.test.ts`（其中的 `HistoricalAnchorSchema` 测试）
- `packages/systems/src/life.ts`（函数 `macroAtBirth`）
- `packages/systems/src/history.ts`

## 允许修改

- `packages/content-schema/src/anchor.ts`
- 新增 `packages/content-schema/src/anchor.test.ts`
- `packages/systems/src/life.ts`：只改 `macroAtBirth` 中的类型判断
- `packages/systems/src/history.ts`：只加对 `polity-change` 的显式处理

## 禁止修改

其他文件；尤其不得改 `golden.ts`、`money.test.ts` 已有断言、合成地区数据。

## 实现要求

1. 在 `HistoricalAnchorSchema` 的 `discriminatedUnion` 中加入：

   ```ts
   z.strictObject({
     ...anchorBase,
     kind: z.literal('polity-change'),
     /** 更替前的政治实体（其有效期应在 at 当天结束）。 */
     fromEntityId: EntityIdSchema,
     /** 更替后的政治实体（其有效期应从 at 当天开始）。 */
     toEntityId: EntityIdSchema,
   }),
   ```

2. 在现有 `superRefine` 中加规则：`polity-change` 的 `fromEntityId !== toEntityId`，否则在 path `['toEntityId']` 报错。
3. 更新文件顶部注释：M1 两类、M2 增加政体更替；作用到在世角色在 M3。
4. `life.ts` 的 `macroAtBirth`：把 `else if (anchor.currencyCode === macro.currency.code)` 改为 `else if (anchor.kind === 'redenomination' && anchor.currencyCode === macro.currency.code)`。政体更替不影响宏观币制与经济阶段。
5. `history.ts`：在处理器开头找到锚点之后，加入

   ```ts
   if (anchor.kind === 'polity-change') {
     throw new Error(`Polity-change anchors are applied from M3 (ADR-0005): ${anchor.id}`);
   }
   ```

   使后面的代码只处理另外两类。不要实现政体更替的效果。

## 验收测试（必须新增，写在 `anchor.test.ts`）

1. 合法的 `polity-change` 锚点通过（夹具：`id: 'anchor:test-polity-change'`、`at: '1991-12-26'`、`regionIds: ['RU']`、`fromEntityId: 'polity:test-old'`、`toEntityId: 'polity:test-new'`，证据用 D 级夹具）。
2. `fromEntityId === toEntityId` 被拒绝。
3. 缺少 `toEntityId`、带多余字段都被拒绝。
4. 旧类型仍然有效：复制一个 `redenomination` 与一个 `economy-phase` 样例并断言通过。
