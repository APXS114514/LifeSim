# M3-003：统计指标契约扩展（教育、劳动力、价格、卫生）

| 项       | 内容                                                               |
| -------- | ------------------------------------------------------------------ |
| 风险     | 高（公共契约）：走 `task/M3-003-indicators` 分支，维护者审查后合并 |
| 前置依赖 | 无                                                                 |
| 涉及模块 | `packages/content-schema`                                          |
| 预计改动 | 修改 1 个文件，修改 2 个测试文件                                   |

## 目标

在 `series.ts` 里扩展 M3 需要的统计指标与单位，让后续 M3-004…006 的数据转换任务有合法的数据格式。**只改契约**：不下载数据、不建序列、不改 `data-registry`。

## 背景

- M2 只有三个指标：`births`、`life-table-qx`、`urban-share`（ADR-0005 §3）。
- M3-B/C 要用教育、劳动力、价格与医疗数据替换 ADR-0006 的 D 级假设。数据来源候选是同一个 WDI 来源（`worldbank-wdi:SP.URB.TOTL.IN.ZS` 已核验为 CC BY 4.0），但**指标 ID 与单位必须先成为契约**，转换脚本才有输出格式。
- 现有单位只有 `thousand-persons`、`probability`、`share`：百分比（0—100）、指数（2010=100）、人均美元放不进去，硬塞进 `share` 会丢失口径。
- 许可证与数据可得性由 M3-004…006 逐项核验；本任务**不得**声称任何新指标已经有数据。

## 必读文件

- `packages/content-schema/src/series.ts`（`INDICATORS`、`INDICATOR_SPEC`、8 条交叉规则）
- `packages/content-schema/src/series.test.ts`

其他所有文件，尤其是 `data-registry`（它的 `urban-share` 特例保持不变）、`country-packs`、`data/`、`systems`、`simulation-core`、`qa/`、`scripts/`。

## 实现要求

### 1. 新增单位

    export const SERIES_UNITS = [
      'thousand-persons',
      'probability',
      'share',        // 0—1
      'percent',      // 0—100
      'percent-gross', // 0—200；毛入学率等按定义可超过 100 的比率
      'index',        // 指数，基期在证据的 methodId 里写明（本项目固定 2010=100）
      'usd-per-capita',
    ] as const;

### 2. 新增指标（ID 必须逐字一致）

| 指标                                   | 含义                                | 单位             | ageBasis |
| -------------------------------------- | ----------------------------------- | ---------------- | -------- |
| `education-enrollment-secondary`       | 中学毛入学率（毛入学率可超过 100%） | `percent-gross`  | `none`   |
| `education-completion-upper-secondary` | 25 岁及以上完成高中及以上的比例     | `share`          | `none`   |
| `labor-force-participation`            | 15 岁及以上劳动参与率               | `share`          | `none`   |
| `employment-agriculture-share`         | 农业就业占总就业比例                | `share`          | `none`   |
| `cpi-index`                            | 消费者价格指数（2010=100）          | `index`          | `none`   |
| `health-out-of-pocket-share`           | 自付卫生支出占经常性卫生支出比例    | `share`          | `none`   |
| `health-expenditure-per-capita`        | 人均经常性卫生支出（现价美元）      | `usd-per-capita` | `none`   |

`INDICATOR_SPEC` 必须同步扩展；`INDICATORS` 的顺序按上表追加在已有三项之后（顺序不影响查询，但测试会逐项遍历）。

### 3. 值域规则（在现有第 8 条规则上扩展）

- `share`、`probability`：闭区间 [0, 1]；
- `percent`：闭区间 [0, 100]；
- `percent-gross`：闭区间 [0, 200]（毛入学率、毛在学率等）；
- `index`：`> 0`（价格指数不会为 0 或负）；
- `usd-per-capita`：`>= 0`；
- `thousand-persons`：`>= 0`。

不要放宽任何现有规则（排序、重复、年份区间、年龄口径、sex 固定 `'both'`）。

### 4. 不做的事

- 不引入分性别序列（Q1 未决）。
- 不引入月度或季度数据。
- 不定义任何「推算规则」（例如 CPI 缺失时插值）——回退仍由 `data-registry` 按 ADR-0005 处理。
- 不新增 `Indicator` 之外的枚举。

## 验收测试（追加到 `series.test.ts`）

1. 每一个新指标各有一个合法夹具序列通过 `StatSeriesSchema`（夹具数值虚构，注释写明「测试夹具，非真实数据」）。
2. `INDICATOR_SPEC` 覆盖 `INDICATORS` 的每一项（现有测试应已覆盖，确认不退化）。
3. `percent-gross` 的值 150 通过、200.1 被拒绝、-1 被拒绝（毛入学率可以超过 100）。
4. `index` 的值 0 被拒绝、1 通过。
5. `usd-per-capita` 的负值被拒绝、0 通过。
6. 指标与单位不匹配被拒绝：`education-enrollment-secondary` 写成 `share`、`cpi-index` 写成 `percent`，错误路径在 `['unit']`。
7. 已有三项指标（births / life-table-qx / urban-share）的既有测试保持通过，不修改它们的断言。
