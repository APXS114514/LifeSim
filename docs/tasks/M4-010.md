## 目标

主角死亡后生成完整人生总结：生平、家庭、教育、职业、经济、健康、迁移、历史事件与决策回顾，全部从事实日志与最终状态派生；**死亡即本局结束**，不得切换到子女继续游戏。

## 背景

- GDD §2 决定 07：死亡结束；撤回「接管子女」；GDD §6.4：主角死亡后停止时间推进，生成完整人生结算与截至死亡时的后代状态，但不能操控后代。
- GDD §10：出生与死亡报告双语。
- 现状：`SummaryCard.tsx` 只显示少量字段（享年、学历、工作年数、余额、事实数）。
- 现有 `summarizeLife` 是纯函数，扩展它而不是在 React 里算。

## 实现要求

1. **扩展 `LifeSummary`**：在现有字段上增加
   - 家庭：婚姻次数、子女数（含收养）、丧偶/离婚、父母是否在世（死亡时）；
   - 教育：最高学历、是否参加考试/录取；
   - 职业：职业类别序列、工作年数、失业次数、退休年龄；
   - 经济：最终余额、币制、负债年数、最大余额；
   - 健康：慢性病列表、治疗次数、死因；
   - 迁移：出生地、最终居住地、迁移次数；
   - 历史：经历的历史锚点（币制、政体、经济周期）与目录事件；
   - 决策：重大决定与玩家/原则的选择。
     所有字段从快照与事实派生；找不到时用 `null`，不得编造。
2. **结束语义**：死亡后控制条禁用、时间线只读、不显示「继续下一代」；仓库不再自动保存新状态。
3. **展示**：总结按章节呈现（生平 / 家庭 / 教育与职业 / 经济 / 健康 / 历史 / 决策），支持折叠；数字与金额本地化但不改币种。
4. **双语**：所有章节标题、字段名、结局说明双语。
5. **导出**：提供「复制总结文本」或下载（不要求 PDF）。

## 验收测试

1. `summarizeLife` 单元测试：用构造的快照与事实断言每个新增字段；缺事实时返回 `null`。
2. 死亡后：控制按钮禁用、没有新事实产生、没有「子女可操控」入口。
3. 渲染：总结章节完整（快照夹具 + 事实），中英都能渲染。
4. 数字：金额与币制与快照一致；日期格式随语言变化但不改日期。
5. E2E：跑到死亡 → 总结显示 → 刷新后仍能查看总结（存档恢复）。
