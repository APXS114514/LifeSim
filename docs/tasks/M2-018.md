# M2-018：俄罗斯（RU，含苏联时期）国家包的地理、政体更替与货币

| 项       | 内容                                                                             |
| -------- | -------------------------------------------------------------------------------- |

| 前置依赖 | M2-014（参考其写法）                                                             |
| 涉及模块 | `packages/country-packs/src/packs/`、`data/sources.json`                         |

## 目标

写出俄罗斯国家包中不含统计序列的部分。M2 的退出条件之一是「苏联—俄罗斯历史映射正确」（GDD §13），这个包就是它的数据。`series: []`。

## 背景（只需知道这些）

- 写法、来源规则、清单格式与 M2-014（`packs/jp.ts`）相同。
- **领土与政体分开**（GDD §5）：`RU` 地区的地点在 1991-12-26 之前属于苏联，之后属于俄罗斯联邦；地点本身不移动，只是政治实体变化。「不能因 1991 年的政治实体更替自动搬动莫斯科居民」。
- 列宁格勒 1991 年改名圣彼得堡：地点 ID 不变，名称按时段变化。
- 「待核实」的日期是预期值：来源证实的值不同、或来源互相矛盾时，停止并报告。

- 货币：`code: 'RUB'`，`initialVersion: 1`，`versionNames`：
  - `'1'`：`{ 'zh-Hans': '苏联卢布（1961 年以前）', en: 'Soviet ruble (before 1961)' }`
  - `'2'`：`{ 'zh-Hans': '卢布（1961—1997）', en: 'Ruble (1961–1997)' }`
  - `'3'`：`{ 'zh-Hans': '俄罗斯卢布', en: 'Russian ruble' }`

  1992—1993 年苏联卢布按 1 : 1 换成俄罗斯卢布，不是重定值，仍属版本 2（在注释里写明）。

- 锚点（`regionIds: ['RU']`；证据 A 级；`modelVersion: 'ru-pack-0.1.0'`；`geographyId: 'country:RU'`；`yearRange` 为该年）：
  - `anchor:ru-redenomination-1961`：`at: '1961-01-01'`（待核实），`currencyCode: 'RUB'`，1 → 2，`divisor: 10`（待核实）；
  - `anchor:ru-polity-change-1991`：`kind: 'polity-change'`，`at: '1991-12-26'`，`fromEntityId: 'polity:ussr'`，`toEntityId: 'polity:ru-russian-federation'`；
  - `anchor:ru-redenomination-1998`：`at: '1998-01-01'`（待核实），2 → 3，`divisor: 1000`（待核实）。
- `breakpoints: []`（政体更替与币制改革都不影响 WPP 按今天领土回溯的人口序列），`series: []`。
- 清单与 JP 相同，`packId: 'RU'`，`geographyId: 'country:RU'`，国家名 `{ 'zh-Hans': '俄罗斯（含苏联时期）', en: 'Russia (incl. Soviet era)' }`；导出 `RU_PACK`。

### 来源

与 M2-014 相同的规则。苏联解体日期可引用联合国或俄罗斯联邦官方资料；城市改名优先引用圣彼得堡市政府或俄罗斯联邦法律文本；重定值优先引用俄罗斯中央银行。

## 验收测试（必须新增，写在 `ru.test.ts`）

1. `validateCountryPack(RU_PACK)` 返回 `[]`；`PACKS.RU === RU_PACK`。
2. `politicalEntityAt(RU_PACK, 'place:ru-moscow', '1991-12-25').id === 'polity:ussr'`；`'1991-12-26'` 为 `polity:ru-russian-federation`；两天的 `adminUnitAt` 都是 `admin:ru-moscow`（居住地不变）。
3. `placeNameAt(RU_PACK, 'place:ru-saint-petersburg', '1991-09-05')` 的英文名为 `Leningrad`；`'1991-09-06'` 为 `Saint Petersburg`；地点 ID 不变。
4. `currencyAt`：`1960-12-31` → 1；`1961-01-01` → 2；`1997-12-31` → 2；`1998-01-01` → 3。
5. 政体更替锚点的 `fromEntityId` / `toEntityId` 与两个政治实体的 `validTo` / `validFrom` 一致（这条由校验规则 10、11 保证，再显式断言一次）。
