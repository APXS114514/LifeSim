# M3-007：经济周期历史锚点（按国家与年代）

| 项       | 内容                                                                        |
| -------- | --------------------------------------------------------------------------- |
| 风险     | 高（国家包数据与来源登记）：走 `task/M3-007-economy-anchors` 分支           |
| 前置依赖 | 无（复用 M1 已有的 `economy-phase` 锚点契约与处理器）                       |
| 涉及模块 | `packages/country-packs`、`data/`                                           |
| 预计改动 | 修改 5 个国家包的 `anchors`、1 个测试文件、来源登记与许可审计、覆盖率与指纹 |

## 目标

给五个国家包补上**有日期、有来源**的经济衰退/复苏锚点，让失业、求职、收入与事件资格按真实年代变化，而不是只在出生时读一次宏观状态。

## 背景

- 现状：`economy-phase` 锚点只有合成地区在用；`packages/real-world/src/region-model.ts` 直接使用国家包的 `anchors`，但五个真实国家包里**一条经济锚点都没有**。所以真实人生里 `macro.economyPhase` 永远是 `normal`，M3-lite 的「衰退乘数」从未生效。
- 契约：`HistoricalAnchorSchema` 的 `economy-phase` 只有 `phase: 'normal' | 'recession'`（ADR-0005 §3）；成对使用：一条 recession 锚点、一条 normal 锚点表示复苏。
- 命名与日期必须可核查：锚点 `id` 形如 `anchor:<pack>-recession-<年>`；`evidence.sourceIds` 指向 `data/sources.json` 中已登记来源；**只引用事实，不再分发史料原文**（`redistribution: 'unknown'` 即可）。
- GDD §9.2：制度断点前后不得线性插值；经济周期是宏观事实，不随玩家选择改变。

- 五个 `packages/country-packs/src/packs/*.test.ts`：追加锚点断言

`packages/systems`、`packages/content-schema`、`packages/real-world`、`apps/`、`qa/`、`scripts/`、`docs/adr`。

## 实现要求

1. 每个国家至少补 1 组、最多 3 组锚点，必须满足：recession 与 recovery 成对、日期严格递增、不重叠、`regionIds` 只含本国、`evidence` 完整。
2. 候选事实（执行者必须逐条核实来源后再写入；核不到就**不加**，在报告里写「未能核实」）：
   - 日本：1973 年第一次石油危机、1991 年泡沫破裂、1997 年金融危机、2008 年全球金融危机；
   - 韩国：1997 年 11 月外汇危机、2008 年全球金融危机；
   - 俄罗斯：1992 年起的转型衰退、1998 年 8 月危机、2008—2009 年危机；
   - 中国大陆：1959—1961 年困难时期（措辞必须中性，证据等级不得冒充 A）、1998 年亚洲金融危机的影响（若可核实）；
   - 朝鲜：1990 年代困难时期（资料极弱，**默认不做**；要做必须由维护者确认 Q10）。
3. 每个锚点的 `evidence.grade` 按来源性质填（官方统计 A、权威机构 B、本游戏推算 C）；`modelVersion` 用国家包版本；`yearRange` 覆盖锚点年份。
4. 来源登记：每个来源一条 `sources.json` 记录（标题、发布者、URL、版本、SPDX 或许可状态、`redistribution: 'unknown'`、`verifiedAt`），并在 `LICENSE_AUDIT.md` 写「只引用事实、不再分发原文」。
5. 不新增数据结构、不加新锚点类型、不改 `RegionModel`。

## 验收测试

1. 每个包：锚点按 `at` 升序；同一时刻没有两条同国锚点；recession 之后必有 recovery；政体/币制锚点顺序不受影响。
2. 锚点 ID 唯一且形如 `anchor:<pack>-<kind>-<年份>`。
3. 用 `createRealLifeSimulation({ region: 'JP', year: 1990 })` 跑到 1995：存在 `history.anchor` 的 recession 与 recovery 事实，且某年的 `finance.settlement` 的 `causes` 指向该衰退事实（若当年发生失业）。
4. 同一国家、同一年出生、同一 seed：加入锚点前后除了新增锚点事实与受影响的就业/收支事实外，不出现日期倒流、不违背不变量。
5. 现有 `pack.test.ts`、`acceptance.test.ts`、`registry.test.ts` 全部通过（不修改断言）。

## 完成定义

- 每个实际生效的锚点都能在 `data/sources.json` 追到来源；无法核实的候选没有被写进去。
- 测试通过；报告里逐国列出「日期、来源、证据等级、是否核实」。

## 可能的阻塞（遇到就停止并报告）

- 某国经济衰退的起止月份在可靠来源里口径不同（例如以季度还是年度计）——报告候选口径，由维护者选定。
- 中国 1959—1961 年的来源与措辞涉及敏感历史（Q10），不得自行决定文本。
- 锚点接入后 `synthetic-world` 的黄金指纹变化（不应发生：合成地区没有国家包锚点；若发生说明改错了地方）。
