# M3-016：死亡风险统一模型回归

| 项       | 内容                                                                        |
| -------- | --------------------------------------------------------------------------- |
| 风险     | 高（死亡语义 + 黄金指纹）：走 `task/M3-016-mortality` 分支                  |

| 涉及模块 | `packages/systems`、`packages/real-world`、`apps/cli`（批量报告）           |

## 目标

锁定「生命表基线 × 个体乘数」的死亡模型：**不重复叠加**、死因与死亡在同一次检查里确定、乘数有上下限、按国家/年份/年龄带的模型死亡率与生命表偏差可测量。M3 验收要求「死亡风险不重复计算，死亡后没有新的主角行为」。

## 背景

- 现状：`health.ts` 已按 `P = 1 - exp(ln(1-q) × m)` 计算，乘数来自疾病/贫困/学历；死亡与死因在同一次检查里抽三次。M3-lite 只有一条慢性病，乘数链很短。
- M3-015 引入多种疾病与长期影响后，乘数会叠加：**必须防止叠乘出畸高死亡率**（GDD §15）。
- 生命表 q 已含全部死因（GDD §8.3），疾病/肥胖/吸烟等只能作为乘数，不能再加独立死因抽样。
- 1injp 的经验（见 [REFERENCE_REUSE](../REFERENCE_REUSE.md) R4）：按年龄带手工校准让群体死亡率吻合生命表；LifeSim 必须把校准系数写成可测试的表，而不是手调后不记录。

## 实现要求

1. **乘数链**：定义有序的乘数列表（疾病严重度、贫困、学历、职业风险、医疗可及性等），依次相乘后按 ADR 规定的上下限截断；每个乘数必须可追溯到一条事实或一个数据来源。
2. **不重复**：删除任何「独立死因抽样」或「疾病死亡概率再加一次」的路径；死因归属只按各因素对总风险强度的贡献比例抽样一次。
3. **死因表**：按年龄带与国家/年代权重的死因分布（D 级，来源写进 ADR）；死因只能是稳定 ID，叙事有 zh/en 模板。
4. **一次性**：每次健康检查最多确定一次死亡；死亡事件安排在当前生日之后、下一个生日之前；死亡后停止全部主角事件（现有不变量保持）。
5. **校准**：批量 1000 局/国家（固定种子），输出按 10 岁年龄带的实际死亡率与生命表 q 的比值；比值超出 ADR 声明容差时报告，不修改断言的期望值来迁就实现。

## 验收测试

1. **不重复叠加**：构造「q 相同、疾病不同」的夹具，断言死亡概率只随乘数变化，且不超过上限。
2. **死因一致**：死亡事实的死因与同一次检查里抽出的归属一致；死于疾病时 `causeEventIds` 包含发病事实。
3. **死后无行为**：批量 200 局，断言死亡日期之后没有任何以主角为 actor 的事实。
4. **校准报告**：RU/JP/CN/KR 各 500 局（KP 单独说明数据局限），年龄别死亡率比值落在 ADR 容差内；报告真实数字。
5. **确定性**：批量报告可复现（固定种子下逐字节相同）。
6. **性能**：`pnpm bench --lives 500` 的 p99 不超过 M3 前的 2 倍（记录两组数字）。

## 可能的阻塞（遇到就停止并报告）

- Q8 没有答复（乘数上下限与容差未定）→ 停止。
- 批量校准显示模型系统性偏离，需要调整数据而非规则 → 报告，不要自行改生命表。
- 需要读取系统时钟或并行随机源才能做批量校准 → 不允许，改用固定种子串行。
