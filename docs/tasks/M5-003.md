# M5-003：校准报告与偏差处理（骨架）

| 项       | 内容                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 风险     | 高（任何参数调整都会改变人生结果）                                                  |
| 前置依赖 | G2（M3 验收）、M5-001、M5-002                                                       |
| 涉及模块 | `apps/cli`（校准报告脚本）、`qa/`；参数调整属于规则或数据任务，另立任务             |
| 执行者   | 报告由执行 Agent；偏差根因与调整方案由 Claude Code 审查；超出容差的处理由维护者决定 |
| 状态     | 骨架，待细化                                                                        |

## 目标

用 M5-001 的批量结果对照 M5-002 的声明，产出 `qa/calibration-report.json` 与可读摘要；对超差指标给出原因与处理（调整、缩小功能并披露、或接受为已知限制）。

## 已定的约束

1. 报告可重现：记录提交、数据包版本、种子与局数。
2. **不得为通过校准而修改统计数据**；只能调整 ADR 中声明为可调的 D 级参数或风险乘数（限幅 0.5—3.0），每次调整另立任务并更新黄金指纹说明。
3. 超差而无法修正的指标进入 `KNOWN_LIMITATIONS.md` 并在界面披露。
4. 同时输出事件重复率（GDD §3.3），作为内容扩容的依据。

## 需要细化的内容

报告格式、摘要表格、超差判定、与上一次报告的比较。

## 验收要点

所有声明的指标都有结果（达标 / 超差 / 未验证）；报告指纹可重现；超差项都有处理记录。

## 可能的阻塞

大量指标超差且需要改规则（交给 Claude Code 做根因分析，维护者决定范围）。
