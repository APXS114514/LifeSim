## 目标

桌面端三栏：左侧人物状态（属性、健康、教育、职业、经济），中间人生时间线，右侧人物关系与历史/统计详情。所有数值来自快照与事实的派生函数，界面不另建权威状态。

## 背景

- GDD §10：桌面主布局左约 20% 角色摘要、中约 55% 时间线、右约 25% 上下文面板；所有关键操作支持点击、触摸、键盘。
- GDD §6.1/§2 决定 11：健康、幸福、经济、知识、关系等表层指标由底层状态派生，不能独立增减。
- 现状：`apps/web` 只有单页时间线与决定卡、总结卡。
- 关系与家庭数据来自 M3 的关系图；界面只读，不写。

## 实现要求

1. **派生指标**（`packages/systems/src/indicators.ts`）：
   - `deriveIndicators(snapshot, facts)` 返回 `{ health, happiness, economy, knowledge, relationships }`，每个 0—1；
   - 每个指标必须由**底层字段**显式计算（健康由疾病严重度与年龄；经济由余额/收入/负债；知识由学历与技能；关系由有效关系的平均 bonds；幸福由健康/经济/关系/重大事件的加权）；
   - 纯函数、无时间、无随机；单测覆盖边界（0/1、空关系、死亡）。
2. **左栏**：姓名/身份（用关系称谓或 ID 的可读形式）、年龄/日期、地区与政体、城乡、五个派生指标、教育、职业、账户余额与币制、当前疾病。
3. **中栏**：时间线（M4-007 负责虚拟化，本任务接好容器与滚动）。
4. **右栏**：关系列表（父母/配偶/子女/其他人 + 关系值与状态）、历史统计（出生地、迁移次数、职业史摘要、数据来源提示）、数据等级披露。
5. **响应式**：宽度 < 1024px 时切到 M4-008 的单栏布局（本任务只负责断点与容器切换）。
6. **无权威副本**：界面不得缓存可写的角色状态；所有显示来自 props（快照派生结果）。
7. **i18n**：面板标题、字段名、空状态文案双语；数字与金额按语言格式化但不改币种。

## 验收测试

1. 派生指标：手工构造快照断言具体数值（三个用例：健康差/经济负/关系空）。
2. 面板渲染：给定快照与事实，左/右栏显示预期字段（Testing Library 或 Playwright）。
3. 模拟结果不变：切换面板/语言不触发任何模拟调用（spy Worker 请求数为 0）。
4. 键盘可达：Tab 顺序、按钮可回车触发。
5. 三栏断点：1024px 以上三栏、以下单栏（E2E viewport 断言）。
6. 双语：所有新增键存在且占位符一致。
