## 目标

用 M3-023 的事件目录为韩国补 3—5 条**有真实状态后果**的年代事件，覆盖教育、职业/经济、家庭或迁移中的至少三类；每条事件都有可核查来源与中英双语叙事。

## 背景

- 韩国：1960 年代出口导向工业化、1970 年代重化工业与新村运动、1988 年汉城奥运会、1997 年 11 月外汇危机（IMF 救济）、2008 年全球金融危机。
- 教育：1969 年中学免试入学与平准化、1970 年代高中入学考试、1990 年代大学入学考试改革；这些属于 M3-012 的制度断点，本任务只做与制度相关的人生事件（例如升学竞争、课外补习）。
- 1997 年危机是本任务最重要的因果链：失业、家庭收入、迁移与健康都受影响。

## 实现要求

1. 事件 ID 形如 `kr.<slug>`，年代窗口与资格必须逐条给出；每条事件的事实类型 = 事件 ID。
2. 至少 3 条、最多 5 条；三条不同类别（教育、职业/经济、家庭/迁移）各至少一条。
3. 每条事件**必须改变至少一个状态字段**（学历、就业、账户、居住地、健康、关系），不能只发事实；不允许「只加背景文案」。
4. 每条事件的事实带 `evidenceIds`，来源在 `data/sources.json` 登记（许可、`redistribution`、`verifiedAt`）；`LICENSE_AUDIT.md` 写明只引用事实。
5. 双语模板：键 = 事件 ID；占位符只来自 `details`；不允许在模板里断言未经核实的统计数字。
6. 叙事尊重当事人处境，不戏谑化困难经历（GDD §3.1）。
7. 不引入该国以外的事件；不把日本的社会制度套用到别国。

1997 年危机的日期与失业率数据必须来自可核查来源（例如韩国统计厅、韩国银行、IMF 文件）。

## 验收测试

1. 每条事件：窗口内固定 seed 至少发生一次；窗口外一次都不发生。
2. 资格：不满足条件的状态不会触发（逐条断言）。
3. 后果：每条事件至少一个状态字段变化（逐条断言具体字段与新值）。
4. 覆盖：该国全部事件都有 zh-Hans 与 en 模板、都有来源、都有 `applies/chance/run`。
5. 预算与确定性：同一年最多 2 条目录事件；同 seed 两次运行一致。
6. 现有测试与不变量全部通过；黄金指纹变化已解释。

## 可能的阻塞（遇到就停止并报告）

- 关键史实来源不可核实或与任务描述不符。
- 需要的状态字段尚不存在（依赖 M3-012/013/014/021）。
- 事件触发的年代与数据包锚点冲突（例如币制改革年份）。
