# M3-024：日本特色事件

| 项       | 内容                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| 风险     | 高（国家内容 + 来源 + 状态后果）：走 `task/M3-024-jp-events` 分支                |
| 前置依赖 | M3-023（事件目录框架）、M3-012（教育规则）                                       |
| 涉及模块 | `packages/systems`、`data/`、`packages/real-world`                               |

## 目标

用 M3-023 的事件目录为日本补 3—5 条**有真实状态后果**的年代事件，覆盖教育、职业/经济、家庭或迁移中的至少三类；每条事件都有可核查来源与中英双语叙事。

## 背景

- 日本是本项目的重点参考国：战后经济高速增长（1955—1973）、1973 年石油危机、1980 年代泡沫与 1991 年破裂、1997 年金融危机、2008 年全球金融危机、2011 年东日本大地震、2020 年疫情。
- 参考项目 1injp 的日本时代内容（昭和/平成流行、学制、就业）只能借鉴**组织方式**（年代分段、生活细节、事件出处），文案与数值不可复制（见 REFERENCE_REUSE §5）。
- 日本学制 1950 年后基本稳定（6-3-3-4），所以教育类事件应侧重「考试竞争、升学率上升、就业冰河期」而不是学制变化。

## 实现要求

1. 事件 ID 形如 `jp.<slug>`，年代窗口与资格必须逐条给出；每条事件的事实类型 = 事件 ID。
2. 至少 3 条、最多 5 条；三条不同类别（教育、职业/经济、家庭/迁移）各至少一条。
3. 每条事件**必须改变至少一个状态字段**（学历、就业、账户、居住地、健康、关系），不能只发事实；不允许「只加背景文案」。
4. 每条事件的事实带 `evidenceIds`，来源在 `data/sources.json` 登记（许可、`redistribution`、`verifiedAt`）；`LICENSE_AUDIT.md` 写明只引用事实。
5. 双语模板：键 = 事件 ID；占位符只来自 `details`；不允许在模板里断言未经核实的统计数字。
6. 叙事尊重当事人处境，不戏谑化困难经历（GDD §3.1）。
7. 不引入该国以外的事件；不把日本的社会制度套用到别国。

## 候选事件（必须逐条核实来源；核不到就换或报告）

| 候选 ID                    | 年代      | 类别      | 后果                                             |
| -------------------------- | --------- | --------- | ------------------------------------------------ |
| `jp.high-growth-job`       | 1955—1973 | 职业      | 求职概率上升、工资增长；农村青年进城就业         |
| `jp.oil-shock`             | 1973—1975 | 经济      | 失业/通胀冲击；家庭消费下降                      |
| `jp.bubble-employment`     | 1986—1991 | 职业      | 招聘扩张、跳槽机会增加                           |
| `jp.ice-age-employment`    | 1993—2005 | 职业/教育 | 应届生求职困难、非正规就业增加                   |
| `jp.great-east-earthquake` | 2011      | 家庭/健康 | 居住地或家庭经济受冲击（按受灾地区资格，需来源） |

注意：泡沫与「就业冰河期」的起止年份在史料中有多种口径，必须选一个来源并写清楚。

## 验收测试

1. 每条事件：窗口内固定 seed 至少发生一次；窗口外一次都不发生。
2. 资格：不满足条件的状态不会触发（逐条断言）。
3. 后果：每条事件至少一个状态字段变化（逐条断言具体字段与新值）。
4. 覆盖：该国全部事件都有 zh-Hans 与 en 模板、都有来源、都有 `applies/chance/run`。
5. 预算与确定性：同一年最多 2 条目录事件；同 seed 两次运行一致。
6. 现有测试与不变量全部通过；黄金指纹变化已解释。
