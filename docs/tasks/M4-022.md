## 产品目标（维护者决定，不得因「现有代码没有」而删减）

以两张《80亿分之1》截图的**信息架构、视觉完整度与信息密度**为目标（不复制其代码、文字、人物、商标与素材），以 `#66CCFF` 为主色，做出「历史档案 × 像素人生 × 动态社会模拟」的原创界面：

1. 有仪式感的**出生登记**：姓名与档案编号并列、人物身份、家庭背景、历史出生地（当时的政体名与旗帜）、出生年代、基础统计、历史背景、地图定位；「重新生成」与「开始这一生」。
2. 人生主界面：顶部时间与历史控制栏；左栏身份档案卡（像素头像）与完整属性面板；中栏随地区/年代/城乡/人生阶段变化的**像素场景**、今年发生了什么、人生记录；右栏「世界档案」：家人与 NPC、同年出生的人、人生方格、生存曲线、所在国家/地区统计。
3. 人生终章：与出生登记呼应的完整人生档案。
4. 地图与边界按真实历史年份显示；展示架构不硬编码为五个地区。
5. 缺数据、缺模型、缺素材时：**保留目标结构与视觉占位并标明「待接入」**，同时建立前置任务；不编造数值，不伪造属性。

## 三、必须经维护者批准的架构变更（批准前不实施）

| 编号 | 变更                                                                                                                                                                                                                                                             | 影响                   |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| N1   | 姓名的存储方式。推荐 (a)：由「种子 + 角色 ID + 出生背景 + 姓名表版本」确定性派生，不进快照，不消耗模拟的随机流；网页存档增加可选字段 `nameTableVersion` 保证旧存档名字不变。备选 (b)：`CharacterState` 增加 `name`（契约变更、快照版本提升与迁移、黄金指纹变化） | 存档（可选字段）或契约 |
| N2   | **姓名依赖性别**：中日韩俄的名字大多区分性别，而性别（Q1 / D4）尚未决定。要么先决定 D4（`sex` 字段 + 分性别生命表，会改变死亡率与黄金指纹），要么姓名系统暂用不区分性别的名字（不自然）。建议 N1 与 D4 一起决定                                                  | 契约、规则、黄金指纹   |
| S1   | 生命表推算方法写入 ADR（上表 STATS），以及推算值在界面上的等级与披露口径                                                                                                                                                                                         | 数据语义               |
| G1   | 地理数据入仓与「政体 → 几何」登记的位置（`country-packs` 或新包）；涉及 `data/`、来源登记与依赖边界                                                                                                                                                              | 数据、依赖边界         |

## 不变的工程约束

- `packages/*`、`golden.ts`、bench、生命周期测试一律不改；界面不消耗随机数、不写事实、只展示权威时钟之前的内容。
- 现有 E2E 依赖的类名与文字保留（`.fact`、`.time-age`、`.time-date`、`.decision-card`、`.decision-option`、`.age-number`、`.character-card`、`.birth-flag`/`.region-flag` 的 `.polity-flag`，「下一年」「播放」「暂停」「速度」「跳转到下一个决定」「直接模拟至结局」「一生总结」「人生时间线」「出生设置」「开始人生」等）。
- 颜色只通过令牌（`apps/web/src/styles/tokens.css`）；像素美术的调色板属于素材数据，集中在 `apps/web/src/pixel/`。
- 不新增依赖；系统字体；不加载外部资源。
- 像素截图不进 CI（macOS 与 CI 字体渲染不同）；CI 只做布局断言；截图存 `Game-Miscellaneous/_verify-lifesim-ui/`。
