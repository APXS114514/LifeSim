| 项       | 内容                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------- |
| 风险     | 高（许可结论由维护者确认；`data/` 属高风险路径）                                                            |
| 前置依赖 | G3（M4 验收）；M5-003（校准结论进入已知限制）                                                               |
| 涉及模块 | `data/LICENSE_AUDIT.md`、`data/SOURCES.md`、`THIRD_PARTY_NOTICES.md`、素材登记、`docs/KNOWN_LIMITATIONS.md` |

## 目标

GDD §9.4 与发布清单：公开构建里的每一份数据、素材、字体、图标都有来源、版本、许可与再分发结论；保留的 P2/P3 与数据局限写进 `KNOWN_LIMITATIONS.md`；构建产物随附第三方声明。

## 已定的约束

1. 只核对与记录，不新增数据或素材；许可不明的条目从公开构建中移除或替换，而不是改写结论。
2. 1injp：只有确实移植的原创代码才登记 MIT 声明；其数据与素材不得出现在构建里。
3. 扫描密钥与个人数据。
4. `KNOWN_LIMITATIONS.md` 至少包括：D 级规则与数据缺口（尤其朝鲜）、校准超差项、未纳入的范围（GDD §3.2）、跨浏览器验证范围。

## 需要细化的内容

构建产物清单与逐项核对表、扫描工具与命令、已知限制的结构与界面披露位置。

## 验收要点

构建产物中每个文件都能对应到登记条目；`pnpm check:licenses`、`pnpm check:data` 通过；扫描无发现；维护者签认许可结论。

## 可能的阻塞

某项数据或素材无法确认可再分发（维护者决定替换或移除）。
