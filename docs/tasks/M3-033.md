## 目标

为「朝鲜富有、韩国尚未工业化之前的南向北迁移」建立严肃、低频、年代严格受限的事件设计：给出史实窗口、可核查来源、资格条件、状态后果、双语叙事要点与测试计划。**本任务不写事件代码**，避免在依赖与内容审查未就绪时把敏感历史塞进规则。

## 背景

- 用户需求：在朝鲜相对富裕、韩国尚未经历朴正熙主导的工业化之前，允许出现「韩国人逃往朝鲜 / 南方人口北迁」的历史可能性。
- 历史范围（必须逐条核实来源，不能凭印象写）：
  - 1945—1948：分治前后的人口流动与越境；
  - 1950—1953：朝鲜战争期间的人口移动（注意：主流叙事中更多是北→南的兴南撤退等，南→北是少数但存在）；
  - 1953—1954：停战后的战俘遣返/选择去向（部分战俘选择北方）；
  - 1950 年代末—1960 年代初：仍有零星知识分子/艺术家北上，但 1961 年朴正熙执政后韩国工业化启动，此后不应再作为常规路径开放。
- 这不是「现代自由迁移按钮」：必须是**事件驱动的重大人生决定**，低频、有资格、有风险、有家庭与国籍后果。
- 资料不足时可用 C/D 级规则，但必须明确标注，不得伪装成精确统计。
- Q10（敏感历史内容分级）未确认；实现前必须由维护者审校事件文本。

## 实现要求（设计文档必须包含）

1. **时间窗口表**：每个候选窗口给出起止日期、政治背景、来源、证据等级（A/B/C/D）、是否适合作为低频事件。
2. **方向区分**：明确「南→北」（本需求）与「北→南」（兴南撤退等）是不同历史现象；不得混为一谈，不得把北→南的史料用来证明南→北规模。
3. **资格条件**（可测试的规则草案）：
   - 出生/居住在大韩民国境内（`place:kr-*`）；
   - 日期窗口内；
   - 家庭或战争处境因子（例如有亲属在北方、战争失所），不得用政治立场评分；
   - 角色年龄与健康；
   - 极低年度概率（给出数量级与依据，或明确标 D 级）。
4. **决策与后果**：
   - 作为重大决定（暂停、玩家可介入）还是自动事件，给出建议与理由；
   - 选择「北上」后：`currentResidenceId` 变为 `place:kp-*`、`politicalEntityId`/`citizenshipIds` 变为 `polity:kp-dprk`；`birthPlaceId` 不变；
   - 家庭分离/共同迁移的规则；
   - 财产、职业资格、健康与后续事件的后果；
   - 不产生「日后可以自由往返」的常规路径。
5. **叙事**：中英双语模板草案（不得直接用于生产，需审校）；不使用真实人名；不提供现实行动细节；不娱乐化。
6. **证据与来源**：列出拟登记到 `data/sources.json` 的来源（标题、机构、URL、许可/再分发状态、拟用证据等级）；来源未核实前不得写具体比例。
7. **实施拆分**：明确实现任务的前置（M3-022 的跨境迁移机制、M3-025 的事件目录、Q10），以及未来测试清单（年代门、资格、低频、状态变化、家庭、双语、确定性）。
8. **不做**：不写代码、不新增事件 ID 到目录、不改国家包。

## 验收测试（文档层面）

1. 文档包含上述 8 节，且每节都有「来源/证据等级/未确认项」标注。
2. 时间窗口与来源逐条对应；无法核实的条目明确写「未确认」，不得留下无来源的具体数字。
3. 方向区分清楚：至少一句话说明为什么不能用北→南的数据推断南→北规模。
4. 资格条件可以转写成测试用例（每条都有可观察的输入与期望）。
5. 后果表覆盖居住地、政体、国籍、家庭、财产、职业与后续事件。
6. 双语模板草案存在，且没有真实人名或现实操作细节。
7. M3-022 与 M3-025 已引用本文档；INDEX 已登记依赖。
