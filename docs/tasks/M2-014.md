## 目标

写出日本国家包中**不含统计序列**的部分：政治实体、行政单位、地点、地点归属、货币。这是五个国家包里最简单的一个，也作为其他四个的写法参考。统计序列在 M2-020 接入，本任务 `series: []`。

## 背景（只需知道这些）

- 国家包格式与校验规则：`packages/country-packs/src/schema.ts`、`validate.ts`（M2-013）。
- 有效期是半开区间：`validFrom` 当天有效，`validTo` 当天不再有效。覆盖期从 1950-01-01 开始，覆盖期之前就已存在且至今不变的实体，`validFrom` 写 `null`。
- M2 只建「代表性城市 + 两个人口池」的骨架（ADR-0005）。
- **已知简化（维护者已决定，照做即可）**：
  - 1952-04-28 之前的盟军占领期不作为政体更替处理，日本在整个覆盖期是同一政治实体（占领期的影响留给 M3 的历史事件）。
  - 冲绳在 1972-05-15 之前由美国管理；M2 不单列冲绳，人口池地点按日本处理。请在本包文件顶部注释中写明这一已知局限。

### 内容（ID、名称与结构按下表；日期以外的内容不要改动）

| 类别     | ID                     | 中文名           | 英文名                     | 其他                               |
| -------- | ---------------------- | ---------------- | -------------------------- | ---------------------------------- |
| 政治实体 | `polity:jp-japan`      | 日本             | Japan                      | `validFrom: null`，`validTo: null` |
| 行政单位 | `admin:jp-tokyo`       | 东京都           | Tokyo Metropolis           | `level: 'province'`                |
| 行政单位 | `admin:jp-osaka`       | 大阪府           | Osaka Prefecture           | `level: 'province'`                |
| 行政单位 | `admin:jp-unspecified` | 日本其他地区     | Other areas of Japan       | `level: 'unspecified'`             |
| 地点     | `place:jp-tokyo`       | 东京             | Tokyo                      | `city`，`urban`                    |
| 地点     | `place:jp-osaka`       | 大阪             | Osaka                      | `city`，`urban`                    |
| 地点     | `place:jp-other-urban` | 日本其他城镇地区 | Other urban areas of Japan | `other-urban`，`urban`             |
| 地点     | `place:jp-other-rural` | 日本其他农村地区 | Other rural areas of Japan | `other-rural`，`rural`             |

- 地点归属：东京 → `admin:jp-tokyo`，大阪 → `admin:jp-osaka`，两个人口池 → `admin:jp-unspecified`；全部属于 `polity:jp-japan`；有效期 `null`—`null`。
- 每个地点只有一个名称时段（`null`—`null`）。
- 货币：`code: 'JPY'`，`initialVersion: 1`，`versionNames: { '1': { 'zh-Hans': '日元', en: 'Japanese yen' } }`；覆盖期内没有币制重定值，`anchors: []`。
- `breakpoints: []`，`series: []`。
- 清单：`{ packId: 'JP', role: 'birth', schemaVersion: '0.1.0', engineRange: '0.1.x', validFrom: '1950-01-01', dataVersion: '0.1.0', licenseManifestPath: 'README.md', modules: {} }`；`geographyId: 'country:JP'`；国家名 `{ 'zh-Hans': '日本', en: 'Japan' }`。
- 导出：`export const JP_PACK: CountryPack`。

### 来源

- 真实史实（东京都、大阪府在覆盖期内持续作为一级行政区；日元在 1950 年后没有币制重定值）要有来源：优先政府、中央银行等官方网页；官方没有时可用权威百科或学术出版物；**维基百科不能作为唯一来源**（可以用来找原始出处）。
- 每个来源登记到 `data/sources.json`：`id` 形如 `<发布者简称>:<主题>`（例如 `boj:yen-history`，须符合 `SourceIdSchema`），`license: 'NOASSERTION'`，`redistribution: 'unknown'`（只引用史实，不再分发数据），填写 `verifiedAt` 与 `notes`（支持哪些史实）。
- 两个人口池地点与 `admin:jp-unspecified` 是设计构造，`sourceIds: ['adr:0005']`。
- 找不到可靠来源、或来源之间说法不一致：停止并报告，**不要自己选一个**。

## 验收测试（必须新增，写在 `jp.test.ts`）
