## 目标

把 WDI 的劳动参与率与农业就业占比转换为 `StatSeries`，为 M3-013 的职业结构与 M3-021 的迁居/城市化提供可核查基线。

## 背景

- 指标：`labor-force-participation`（share，WDI `SL.TLF.CACT.ZS`，注意 API 返回的是 0—100 的百分比，转换成 0—1 时除以 100 并保留足够精度）、`employment-agriculture-share`（share，WDI `SL.AGR.EMPL.ZS`）。
- 口径陷阱：WDI 的 `SL.TLF.CACT.ZS` 默认是「15 岁及以上、ILO 模型估计」，属于 B/C 级模型结果；转换脚本必须在 `methodId` 与 `LICENSE_AUDIT` 备注里写清楚口径，不得当成各国官方普查值。
- 朝鲜同样可能缺观测，处理方式与 M3-004 相同。

## 必读文件

与 M3-004 相同，另加：

- `packages/real-world/src/region-model.ts`（只是确认消费方字段，不改）
- M3-004 的输出与 `inputs.json`（复用抓取与校验工具，避免重复实现）

## 允许修改

与 M3-004 相同，把文件名换成 `data/scripts/worldbank/labor.ts` 与 `labor.test.ts`，生成文件为 `wdi-labor-*.json`。

## 禁止修改

同 M3-004。

## 实现要求

1. 复用 M3-004 引入的下载/缓存/校验函数（若它还没有可复用函数，先在本任务里抽成 `data/scripts/worldbank/fetch.ts` 并在测试里覆盖；不要复制粘贴两份实现）。
2. 百分比 → share 的换算只在转换层进行，序列里存 0—1；断言 0—100 之外的原始值被拒绝（视为数据错误，不静默裁剪）。
3. 证据等级：`grade: 'B'`（ILO 模型估计，经世界银行发布），`methodId: 'wdi-<code>-share'`；若维护者要求把模型估计降为 C，按 Q4 的答复执行。
4. 其余（空值、来源登记、接入国家包、指纹、覆盖率）与 M3-004 逐条相同。

## 验收测试

1. `labor.test.ts`：换算精度（例如 62.345678 → 0.62345678，不因四舍五入损失 1e-6 以上）、拒绝 >100 的原始值、点排序、缺失不补 0。
2. 每个有序列的国家：劳动参与率与农业就业占比的年份覆盖与 WDI 一致；报告列出缺失年份。
3. 现有测试与门禁全部通过。

## 完成定义

## 可能的阻塞

- WDI 的 `SL.TLF.CACT.ZS` 对不同国家使用不同年龄下限（15+ 与 10+ 混用），无法统一口径——报告具体国家与年份，由维护者决定是否只保留 15+ 年份。
- 农业就业占比在 1950—1990 年大量缺失，回退规则会把它变成 D 级前延；报告缺失比例。
