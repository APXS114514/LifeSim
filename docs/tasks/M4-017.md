## 目标

现在最慢每年 2 秒，一生约 3 分钟，且一年的事件一次性出现。参考 1in8b 与 1injp 的节奏：开局可选「一生时长」（例如约 10、30、60 分钟），播放中可再调倍速；一年内的事件按年度进度条逐条出现。

## 已定的约束

1. **仍然每个 tick 只推进一个周年节点**（M3-034 的约束不变），绝不预先模拟后面的年份。
2. 年内逐条出现只是展示：这一年的事实已经由内核算出并保存，界面按进度依次显示。显示的日期**不得超过权威时钟**；暂停时停止显示进度；刷新或读档后直接显示到权威时钟为止的全部事实。
3. 遇到重大决定时，内核停在决定日期，界面显示到该日期的事实后弹出决定卡。
4. 一生时长与倍速是界面偏好（`lifesim.prefs.v1`），不写进存档、不影响结果。
5. M3-034 的单元测试与 E2E 只能扩展，不能放宽。

## 需要细化的内容

时长与倍速档位、进度条与逐条显示的实现、可访问性（减少动态效果的系统设置下直接显示）、测试。

## 验收要点

逐条显示与一次性显示的事实集合相同；显示日期始终 ≤ 权威时钟；暂停后进度不动；刷新后不丢失、不重复；E2E 覆盖桌面与手机。
