# M2-019：数据许可门禁：国家包引用的来源必须登记，派生数据必须可再分发

| 项       | 内容                                                               |
| -------- | ------------------------------------------------------------------ |
| 风险     | 高（质量门禁）：PR 需维护者审查并加 `arch-approved` 标签           |
| 前置依赖 | M2-004、M2-020（数据文件全部接入国家包之后，孤立文件检查才有意义） |
| 涉及模块 | `scripts/check-data.mjs`                                           |
| 预计改动 | 修改 2 个文件                                                      |

## 目标

把 GDD §9.4「数据包未通过许可审计不得合入公开构建」变成 CI 中自动执行的检查。M2-004 的 `check:data` 目前只检查 `sources.json` 本身；本任务让它同时检查国家包。

## 背景（只需知道这些）

- 国家包登记在 `packages/country-packs/src/packs/index.ts` 的 `PACKS` 中（M2-013），格式见 `src/schema.ts`。
- 来源 ID 有两种：登记在 `data/sources.json` 里的外部来源；形如 `adr:0005` 的设计决定，对应 `docs/adr/0005-*.md`。
- 史实引用（地理、锚点的 `sourceIds`）只要求来源已登记；**统计序列**的外部来源必须是 `redistribution: 'allowed'`，因为序列数据本身会被再分发。
- 根目录脚本可以直接导入 `.ts` 源码（例如 `../packages/country-packs/src/index.ts`）。

## 必读文件

- `scripts/check-data.mjs`、`scripts/check-data.test.ts`（M2-004）
- `packages/country-packs/src/schema.ts`、`src/packs/index.ts`

## 实现要求

新增并导出纯函数：

```js
/**
 * @param {readonly import('../packages/country-packs/src/index.ts').CountryPack[]} packs
 * @param {readonly import('../packages/content-schema/src/index.ts').SourceRecord[]} sources
 * @param {readonly string[]} adrNumbers   docs/adr 下已有的编号，例如 ['0001', '0005']
 * @param {readonly string[]} dataFiles    packages/country-packs/data 下的 JSON 文件相对路径
 * @param {ReadonlySet<string>} importedSeriesIds  各包 series 中出现的序列 id
 * @returns {string[]}
 */
export function checkPackSources(packs, sources, adrNumbers, dataFiles, importedSeriesIds);
```

规则（每条问题文本包含包 ID 与来源 ID 或文件名）：

1. 国家包中出现的每个来源 ID（政治实体、行政单位、地点、地点归属的 `sourceIds`，锚点与序列证据的 `sourceIds`，断点的 `sourceIds`）：若以 `adr:` 开头，编号必须在 `adrNumbers` 中；否则必须在 `sources` 中。
2. 每个序列证据中的外部来源（非 `adr:`）必须是 `redistribution: 'allowed'`；否则报告「派生数据来自尚未确认可再分发的来源」。
3. `dataFiles` 中的每个文件都必须被某个包导入（其序列 `id` 在 `importedSeriesIds` 中）；没有被导入的数据文件报告为「孤立数据文件」。文件与序列 id 的对应规则：读取文件内容，取其中的 `id` 字段。

命令行模式（`node scripts/check-data.mjs`）在原有检查之后执行本检查：从 `PACKS` 取出已加入的包，扫描 `docs/adr/` 得到编号，扫描 `packages/country-packs/data/**/*.json`（目录不存在时视为空），读取每个文件的 `id`。任何问题都使退出码为 1。`--write` 模式不受影响。

## 验收测试（新增到 `scripts/check-data.test.ts`）

用夹具包与夹具来源（注释标明夹具）：

1. 全部来源已登记、序列来源为 `allowed`：返回 `[]`。
2. 地点引用未登记的来源：报告，且包含来源 ID。
3. 引用不存在的 ADR 编号：报告。
4. 序列来源为 `unknown` / `restricted`：报告「尚未确认可再分发」。
5. 史实来源为 `unknown`：**不**报告（史实引用不要求可再分发）。
6. 有数据文件未被任何包导入：报告「孤立数据文件」。
7. 对仓库当前状态运行命令行模式：通过。
