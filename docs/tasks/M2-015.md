## 目标

写出韩国国家包中不含统计序列的部分，包括两次币制重定值与釜山行政地位的变化。`series: []`。

## 背景（只需知道这些）

- 写法、来源规则、清单格式与 M2-014（`packages/country-packs/src/packs/jp.ts`）完全相同，照抄结构。
- 有效期是半开区间；覆盖期从 1950-01-01 开始。
- 表中带「待核实」的日期是维护者给出的**预期值**：你必须用来源核实。来源证实的日期与预期不同，或来源互相矛盾，**停止并报告**，不要自行改用别的日期。

  - `'1'`：`{ 'zh-Hans': '圆（1953 年以前）', en: 'Won (before 1953)' }`

  - `'3'`：`{ 'zh-Hans': '韩元', en: 'Won' }`
- 锚点（`regionIds: ['KR']`，证据 `grade: 'A'`、`sourceIds` 为核实用的来源、`modelVersion: 'kr-pack-0.1.0'`、`geographyId: 'country:KR'`、`yearRange` 为该年）：
  - `anchor:kr-redenomination-1953`：`at: '1953-02-15'`（待核实），`currencyCode: 'KRW'`，1 → 2，`divisor: 100`；
  - `anchor:kr-redenomination-1962`：`at: '1962-06-10'`（待核实），2 → 3，`divisor: 10`。
- `breakpoints: []`（币制改革不影响 M2 的三个指标），`series: []`。
- 清单与 JP 相同，`packId: 'KR'`，`geographyId: 'country:KR'`，国家名 `{ 'zh-Hans': '韩国', en: 'South Korea' }`；导出 `KR_PACK`。
- 文件顶部注释写明已知简化：朝鲜战争期间首尔曾两度被占领，M2 不作为政体变化处理（留给 M3 的历史事件）。

### 来源

与 M2-014 相同的规则。币制重定值的日期与兑换比例优先引用韩国银行（Bank of Korea）等官方来源；釜山的行政地位变化优先引用政府来源。

## 验收测试（必须新增，写在 `kr.test.ts`）

1. `validateCountryPack(KR_PACK)` 返回 `[]`；`PACKS.KR === KR_PACK`。
2. `adminUnitAt(KR_PACK, 'place:kr-busan', '1962-12-31').id === 'admin:kr-gyeongnam'`；`'1963-01-01'` 为 `admin:kr-busan`。
3. `currencyAt`：`1953-02-14` → 版本 1；`1953-02-15` → 2；`1962-06-09` → 2；`1962-06-10` → 3；`2026-12-31` → 3。
4. 两个重定值锚点的 `divisor` 分别为 100、10。
