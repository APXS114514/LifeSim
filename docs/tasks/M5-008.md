## 目标

按 RELEASE_CHECKLIST 产出发布候选：报告、变更记录、可重建的构建、`v0.1.0-alpha.N` 标签，部署到静态托管并在缓存后实测离线可玩。

## 已定的约束

1. RELEASE_CHECKLIST 任何一项未满足，只能发布「候选」并列出阻碍，不得勾选未完成的项目。
2. 同一提交重复构建产物逐字节相同（固定数据包版本与依赖）。
3. 报告只写实际运行过的测试与真实数字（测试数量、失败用例、机器与浏览器、性能分布、统计误差、种子）。
4. 不在首版放任何伪可用的 AI、账号或云同步按钮（GDD §3.2、§6.4）。

## 需要细化的内容

报告生成脚本、可重建性检查、部署工作流与基础路径、部署后的离线验证步骤。

## 验收要点

发布清单全部勾选或明确列为阻碍；报告可由脚本重新生成；部署站点在断网后可玩（已缓存）。

## 可能的阻塞

D11 未决定；任何 P0 或关键路径 P1 未清零。
