## 目标

RELEASE_CHECKLIST 与 M5 交付：Chromium、Firefox、WebKit 三个引擎都能完成核心流程，且**同一种子与选择在三个引擎里产生逐字节相同的事实**（风险换算用 `expDet` / `lnDet` 就是为此；目前只在 V8 上实测过）。

## 已定的约束

1. 跨引擎一致性测试比较规范事实 JSON 的指纹，不比较截图。
2. 不为某个浏览器改规则；发现不一致时停止并交给 Claude Code 做根因分析（P0：「相同 seed+输入结果不一致」）。
3. 本机没有 Playwright 自带浏览器时用 `PW_CHANNEL`；CI 安装三个引擎。

## 需要细化的内容

三引擎项目配置、一致性测试的种子集合、CI 时长预算。

## 验收要点

三引擎的冒烟流程全部通过；固定种子集合在三引擎中的事实指纹相同。

## 可能的阻塞

某引擎的数学或排序与 V8 不同导致结果分叉。
