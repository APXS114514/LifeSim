# M5-005：无障碍与双语审查（骨架）

| -------- | ------------------------------------------------- |
| 风险     | 中（新增开发依赖需许可检查）                      |

## 目标

M5 交付的「双语/无障碍审查」与发布清单的「翻译覆盖率 zh-Hans 与 en 100%」：所有关键操作可用键盘与触屏完成、不依赖悬停（GDD §10），读屏器可读，颜色对比合格，翻译覆盖率有报告。

## 已定的约束

1. 不改模拟结果；只改界面结构、标签与样式。
2. 新增的自动化检查工具必须通过 `pnpm check:licenses`，版本写死。
3. 翻译覆盖率报告由脚本生成（键集合与占位符一致），不是人工估计。

## 需要细化的内容

检查清单（键盘路径、焦点顺序、`aria-*`、对比度、动态内容播报）、自动化工具选择与 E2E 用例、覆盖率报告格式。

## 验收要点

自动化无障碍检查在核心页面零严重问题；键盘完成创建 → 推进 → 决定 → 生平报告；翻译覆盖率 100%。

## 可能的阻塞

需要改设计令牌或布局才能达到对比度要求（与 M4-006/008 的维护者协调）。
