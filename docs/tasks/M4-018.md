## 目标

在若干人生节点（例如 5、15、30、50、70 岁）暂停，提出一个与这段人生有关的问题，玩家可以留一句话；生平报告里回顾这些话。这是 1in8b 与 1injp 里最打动人的环节之一。

## 已定的约束

1. 问题由我们原创撰写（中英），**不得复制** 1in8b 或 1injp 的文字。
2. 留言只存在本机存档里（`GameSaveData` 增加**可选**字段，旧存档缺省为空），**不进入模拟状态、不影响任何结果**；不上传。
3. 可在设置里关闭；自动播放时可选择跳过。
4. 内容平和、不诱导；遇到严肃人生经历（重病、丧亲）时措辞克制。

## 验收要点

节点触发准确（按权威时钟的周岁）；留言往返存档；关闭后不再暂停；结果不受影响（有无留言事实逐字节相同）；E2E。
