## 目标

在 `content-schema` 中加入统计序列的 zod schema，作为后续 DataRegistry 与所有数据文件的唯一格式。**只加契约与测试，不写任何读取或查询逻辑。**

## 背景（只需知道这些）

- 一个统计序列 = 一个指标（如年出生数）在一个地理单位上、按年（必要时按单岁年龄）的一组数值，带证据元信息（ADR-0005 §3）。
- 缺失值必须是 `null` 并附原因，不能写 0（GDD §9.2）。
- WPP 2024 中 2024 年起的数值是预测，用每个点上的 `projected` 标记。
- M2 只有男女合计数据，因此 `sex` 固定为 `'both'`。

## 实现要求

`series.ts` 的内容按下面的定义实现（可以调整格式与注释措辞，**不得改变任何字段、取值、规则或错误条件**）：

```ts
import { z } from 'zod';
import { EvidenceMetaSchema } from './evidence.ts';
import { EntityIdSchema } from './primitives.ts';

/** M2 的统计指标（ADR-0005 §3）。新增指标需要架构审查。 */
export const INDICATORS = ['births', 'life-table-qx', 'urban-share'] as const;
export const IndicatorSchema = z.enum(INDICATORS);
export type Indicator = z.infer<typeof IndicatorSchema>;

export const SERIES_UNITS = ['thousand-persons', 'probability', 'share'] as const;
export type SeriesUnit = (typeof SERIES_UNITS)[number];
export const AGE_BASES = ['none', 'single-year'] as const;
export type AgeBasis = (typeof AGE_BASES)[number];

/** 每个指标固定的单位与年龄口径。 */
export const INDICATOR_SPEC: Record<Indicator, { unit: SeriesUnit; ageBasis: AgeBasis }> = {
  births: { unit: 'thousand-persons', ageBasis: 'none' },
  'life-table-qx': { unit: 'probability', ageBasis: 'single-year' },
  'urban-share': { unit: 'share', ageBasis: 'none' },
};

const pointBase = {
  year: z.number().int().min(1900).max(2300),
  /** 单岁年龄；ageBasis 为 'none' 时必须为 null。 */
  age: z.number().int().min(0).max(120).nullable(),
  /** 是否为预测值。 */
  projected: z.boolean(),
};

export const SeriesPointSchema = z.union([
  z.strictObject({ ...pointBase, value: z.number() }),
  z.strictObject({ ...pointBase, value: z.null(), missingReason: z.string().min(1) }),
]);
export type SeriesPoint = z.infer<typeof SeriesPointSchema>;

/** 例如 `wpp2024/CN/births`：来源/地区包/指标。 */
export const SeriesIdSchema = z
  .string()
  .regex(/^[a-z0-9]+(?:-[a-z0-9]+)*\/[A-Z]{2}(?:-[A-Z0-9]+)?\/[a-z0-9]+(?:-[a-z0-9]+)*$/);

export const StatSeriesSchema = z
  .strictObject({
    id: SeriesIdSchema,
    indicator: IndicatorSchema,
    geographyId: EntityIdSchema,
    unit: z.enum(SERIES_UNITS),
    ageBasis: z.enum(AGE_BASES),
    sex: z.literal('both'),
    evidence: EvidenceMetaSchema,
    points: z.array(SeriesPointSchema).min(1),
  })
  .superRefine((series, ctx) => {
    // 规则见下表
  });
export type StatSeries = z.infer<typeof StatSeriesSchema>;
```

`superRefine` 必须逐条检查下表；每个违规都 `ctx.addIssue({ code: 'custom', message, path })`：

| #   | 规则                                                                                   | path                     |
| --- | -------------------------------------------------------------------------------------- | ------------------------ |
| 1   | `unit` 等于 `INDICATOR_SPEC[indicator].unit`                                           | `['unit']`               |
| 2   | `ageBasis` 等于 `INDICATOR_SPEC[indicator].ageBasis`                                   | `['ageBasis']`           |
| 3   | `geographyId` 等于 `evidence.geographyId`                                              | `['geographyId']`        |
| 4   | `ageBasis === 'none'` 时每个点 `age === null`；`'single-year'` 时每个点 `age !== null` | `['points', i, 'age']`   |
| 5   | 同一 `(year, age)` 不得重复                                                            | `['points', i]`          |
| 6   | 点按 `year` 升序、同年按 `age` 升序（严格递增；`age` 为 null 时按 `year` 比较）        | `['points', i]`          |
| 7   | 每个点的 `year` 在 `evidence.yearRange` 的闭区间内                                     | `['points', i, 'year']`  |
| 8   | 非 null 的 `value`：`probability`、`share` 必须在 [0, 1]；`thousand-persons` 必须 ≥ 0  | `['points', i, 'value']` |

## 验收测试（必须新增，写在 `series.test.ts`）

在测试文件里定义两个**夹具**（数值是虚构的，注释写明「测试夹具，非真实数据」）：

- `births`：`id: 'test/CN/births'`，`geographyId: 'country:CN'`，三点 1950、1951、2024（2024 的 `projected: true`），值 20000、20500.5、9000，证据 `grade: 'B'`、`sourceIds: ['un-wpp:2024']`、`yearRange: [1950, 2100]`。
- `qx`：`indicator: 'life-table-qx'`，同一年 2000 的 age 0、1、2 三点，值 0.01、0.001、0.0005。

必须有以下测试（每条一个 `it`）：

1. 两个夹具都能通过 `StatSeriesSchema`。
2. 缺失点 `{ year, age: null, value: null, missingReason: '…', projected: false }` 可以通过；去掉 `missingReason` 则失败。
3. 规则 1—8 每条各有一个违反它的样例被拒绝（共 8 个断言，可以用 `it.each`）。
4. 未知指标（如 `'gdp'`）与多余字段被拒绝。
5. `INDICATOR_SPEC` 覆盖 `INDICATORS` 中的每一个指标。
