# 数据政策

> **规范来源是 [GDD.md](GDD.md) §9**（数据分级、回退规则、校准方法、资源许可）。本文把它落实为仓库里的具体流程，并登记已知的待核实事项。

## 证据等级

| 等级 | 含义                                       | 例子                                 |
| ---- | ------------------------------------------ | ------------------------------------ |
| A    | 原始或直接的官方统计（仍需核实口径与偏差） | 国家统计机构公布的年度出生数         |
| B    | 权威机构的模型估计或预测                   | 联合国人口司的生命表估计与预测       |
| C    | 本游戏明示来源和方法的间接估计             | 用上级地区数据加城乡修正推出的省级值 |
| D    | 为可玩性引入的设计假设                     | M1 的合成地区数据包                  |

等级不是置信概率。数据质量、不确定性、适用地域与年份、许可状态是彼此独立的元信息，对应 `EvidenceMeta` 与 `SourceRecord` 两个 schema（`packages/content-schema/src/evidence.ts`）。

## 硬性规则（由 schema 强制）

- 每个统计值都要带 `EvidenceMeta`，并且至少引用一个来源 ID；D 类假设引用记录该假设的 ADR（例如 `adr:0003`）。
- 缺失值是 `null`，并且必须附 `missingReason`。不能写成 0，也不能悄悄插值。
- 不确定区间下界不得大于上界，年份区间必须是 `[起, 止]`。
- 来源只有在核验过许可条款（填写了 `verifiedAt`）之后，才能标记为可再分发（`redistribution: "allowed"`）。

## 流程

1. **登记来源**：在 [data/SOURCES.md](../data/SOURCES.md) 加一行，字段与 `SourceRecord` 一致：ID、标题、发布者、URL、版本、SPDX 许可证、再分发状态、核验日期、备注。
2. **存放原始数据**：只有可再分发的原始文件才能放进 `data/sources/`；不可再分发的数据只登记获取方式，由脚本在本地下载，并加入 `.gitignore`。
3. **派生数据**：由 `data/scripts/` 里的脚本生成到 `data/derived/`，脚本记录方法 ID，输出带证据元信息。
4. **许可审计**：M2 起维护 `data/LICENSE_AUDIT.md`，逐个数据集记录条款原文链接、是否允许再分发与修改、署名要求、核验人和日期。未通过审计的数据不进公开构建（GDD §9.4）。
5. **制度断点**：苏联解体、币制改革、教育制度改革、行政区划调整等断点前后不做线性插值（GDD §9.2），断点本身作为有日期的规则登记。

## 已知待核实事项（进入 M2 时处理）

以下内容来自设计评审，**尚未经过来源核实**，不能直接作为数据使用：

- **币制版本**：GDD §8.1 只点名了苏联/俄罗斯，但 1950—2026 年间五个地区中有四个发生过货币重定值，都需要做成有日期的转换规则，并纳入 M2 的边界测试：
  - 中国大陆：1955 年发行新人民币，与旧币按 1:10000 兑换；
  - 韩国：1953 年 圆→환（100:1），1962 年 환→원（10:1）；
  - 朝鲜：1959 年与 2009 年各进行过一次 100:1 的重定值；
  - 苏联/俄罗斯：1961 年（10:1）、1998 年（1000:1）；
  - 日本：这段时间内没有重定值。
- **联合国 World Population Prospects**：许可条款需按版本逐一核验，不能默认等同 MIT（GDD §9.4）。
- **世界银行开放数据**：多数是 CC BY 4.0，但要逐个数据集确认。
- **Natural Earth**：自有数据声明为公有领域，但要区分其中第三方派生的内容。
- **朝鲜与 1960 年以前的地区统计**：预计大量缺失，需要设计明确的回退规则，并在界面中提示局限。
