# 路线图

> 里程碑的交付内容与退出条件以 [GDD.md](GDD.md) §13 为准，对应的 Agent 任务原文在 [AGENT_PROMPTS.md](AGENT_PROMPTS.md)。每个阶段验收之后才进入下一阶段。

| 里程碑 | 内容                       | 状态             |
| ------ | -------------------------- | ---------------- |
| M0     | 冻结规范与仓库地基         | 已验收           |
| M1     | 可复现的单人人生模拟内核   | **完成，待验收** |
| M2     | 五国数据包与证据登记       | 未开始           |
| M3     | 人生系统与程序化内容集成   | 未开始           |
| M4     | 公开可玩体验与安全存档     | 未开始           |
| M5     | 统计校准、性能与公开 Alpha | 未开始           |

依赖顺序（GDD §13）：M1 是 M2、M3、M4 权威逻辑的前提；M2 的国家数据样本可以和 M1 并行准备；M4 的界面外壳可以提前做，但不能另写一套假规则；测试和校准的基础从 M0/M1 就开始建。

## M0：仓库地基（已验收）

GDD 与任务原文入库、pnpm monorepo、类型契约与 schema 校验、双语资源与角色创建页草图、全部质量门禁与 CI、协作文件、ADR-0001/0002。

## M1：确定性人生模拟内核

- [x] 世界日期与时段推进：整数日历运算，逐年 / 快进 / 自动共用 `advanceTo`
- [x] 事件系统：全序队列、幂等键、资格条件、同日连锁与事件风暴上限、循环检测
- [x] 原子状态变更：草稿—校验—提交，失败不留状态，错误带种子 / 事件键 / 日期
- [x] 单调事件日志：连续序号、日期不倒流、原因只指向更早的事实
- [x] 随机种子与独立随机流（计数器式派生），确定性 exp/ln（ADR-0004）
- [x] 角色状态与稳定 ID；人生原则规则引擎；重大决定暂停与玩家选择；普通决定自动处理
- [x] 历史锚点调度：币制重定值（账户 BigInt 换算）、经济衰退与复苏
- [x] 教育 → 就业 → 家庭财务 → 健康 → 死亡的最小因果链；死亡终止
- [x] 合成地区（D 类，ADR-0003），不冒充真实统计
- [x] 快照与恢复；存档文件编码解码后继续推进与不中断一致
- [x] headless CLI（`pnpm life`）与可复现的性能基准（`pnpm bench`）
- [ ] 验收：维护者确认交付报告；CI 在 GitHub 上通过

## 进入 M2 之前

- 读 GDD §4.2、§4.3、§5、§9 与 [DATA_POLICY.md](DATA_POLICY.md)。
- 用 `RegionModel` 接口接入真实国家包；按 GDD 的回退规则建 DataRegistry，所有数值带证据等级与来源。
- 历史锚点要扩展到政体更替（苏联 → 俄罗斯联邦）与行政区划变化；当前只有币制与经济阶段两类。

## M2 入口待办

- 币制版本覆盖五地中的四地，而不只是苏联/俄罗斯（详见 [DATA_POLICY.md](DATA_POLICY.md)「已知待核实事项」）。M2 的边界测试除了 GDD 列出的 1950、1970、1991、1997、2026，还要加上 1953、1955、1959、1961、1962、1998、2009。
- 苏联解体按准确日期（1991-12-26）处理：1991 年出生的角色，出生时的政治实体取决于出生日期，而不是出生年份。
- 逐个数据集核验许可（联合国、世界银行、Natural Earth 等），产出 `data/LICENSE_AUDIT.md`。
