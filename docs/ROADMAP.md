# 路线图

> 里程碑的交付内容与退出条件以 [GDD.md](GDD.md) §13 为准，对应的 Agent 任务原文在 [AGENT_PROMPTS.md](AGENT_PROMPTS.md)。每个阶段验收之后才进入下一阶段。

| 里程碑 | 内容                       | 状态             |
| ------ | -------------------------- | ---------------- |
| M0     | 冻结规范与仓库地基         | **完成，待验收** |
| M1     | 可复现的单人人生模拟内核   | 未开始           |
| M2     | 五国数据包与证据登记       | 未开始           |
| M3     | 人生系统与程序化内容集成   | 未开始           |

## 进入 M1 之前

- 读 GDD §4.1、§6、§7、§8.3、§11.4 与 §17（首个垂直切片）。
- M1 只用一个明确标注为 D 类的**合成地区数据包**，不冒充真实统计。
- 要设计的关键点：随机流按「根种子 + 子系统 + 实体 ID + 时段 + 事件 ID」派生；`rngState` 与调度器状态完整写入快照；事件幂等键；单步触发上限。
