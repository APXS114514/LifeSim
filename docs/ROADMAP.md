# 路线图

> 里程碑的交付内容与退出条件以 [GDD.md](GDD.md) §13 为准，对应的 Agent 任务原文在 [AGENT_PROMPTS.md](AGENT_PROMPTS.md)。每个阶段验收之后才进入下一阶段。

| 里程碑 | 内容                       | 状态                                                                                                                 |
| ------ | -------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| M0     | 冻结规范与仓库地基         | 已验收                                                                                                               |
| M1     | 可复现的单人人生模拟内核   | **完成，待验收**（审计见 [audits/M1-AUDIT.md](audits/M1-AUDIT.md)）                                                  |
| M2     | 五国数据包与证据登记       | **已实现，待验收**（23 个任务，见下节）                                                                              |
| M3     | 人生系统与程序化内容集成   | **进行中**：M3-000…010、031…033 已推送待验收；M3-035 合并后 CI 已恢复通过（[接手审计](audits/M3-TAKEOVER-AUDIT.md)） |
| M4     | 公开可玩体验与安全存档     | 任务已拆分（[M4-001…015](tasks/INDEX.md)），待 M3 验收后开始                                                         |
| M5     | 统计校准、性能与公开 Alpha | 已拆分为骨架任务 M5-001…008（[V0.1_PLAN](V0.1_PLAN.md)）                                                             |

依赖顺序（GDD §13）：M1 是 M2、M3、M4 权威逻辑的前提；M2 的国家数据样本可以和 M1 并行准备；M4 的界面外壳可以提前做，但不能另写一套假规则；测试和校准的基础从 M0/M1 就开始建。

设计见 [ADR-0005](adr/0005-m2-data-architecture.md)；任务队列、依赖与验收状态见 [docs/tasks/INDEX.md](tasks/INDEX.md)。M2 不修改 `systems` 与 `RegionModel`，真实地区接入人生规则在 M3。

- [x] `StatSeries`、地理（半开区间）与 `polity-change` 锚点契约

- [x] `data-registry`：精确查询、相邻年份 / 上级地理 / 首个观测值前延 / 情景规则，断点与预测标记
- [x] WPP 2024 出生数与单岁生命表（男女合计）、世界银行城镇比例转换（SHA-256 校验、可重复生成）

- [x] `createPackRegistry`、15 条数据指纹与出生选择器（GDD §4.3）
- [x] 五地 1950—2026 实例化验收测试、数据覆盖率矩阵与许可门禁
- [ ] 验收：维护者确认（CI、Guardrails / `arch-approved`、来源复核）

已登记但需要维护者复核的史实取舍：重庆 1997 年采用 6 月 18 日正式挂牌日（全国人大批准日为 3 月 14 日）；苏联解体采用 1991-12-26 宣言（12 月 25 日为戈尔巴乔夫辞职与降旗）；朝鲜资料来自韩国官方教育/研究机构，非朝鲜官方来源。详见各国家包文件顶部注释与 [data/LICENSE_AUDIT.md](../data/LICENSE_AUDIT.md)。
