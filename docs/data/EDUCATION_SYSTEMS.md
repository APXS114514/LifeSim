## 1. 结论摘要

- 五个国家包共 **15 个学制分段**（CN 5、JP 1、KP 2、KR 3、RU 4），全部仍为 **D 级设计假设**：
  每段都含未由法规决定的 `entranceExam.passBase` 与 `feeShare`，段级 `grade` 按最弱值取 D。
  逐值等级见 §4；没有把 D 级参数冒充成 C 级。
- 本任务登记了 **9 条来源**（`data/sources.json`，全部 `NOASSERTION` / `redistribution: unknown`，
  只引用史实或法律事实，不再分发原文），用于核实年份边界与历史注释。来源清单见 §3。
- 本任务核实的 5 组历史注释全部找到可引用来源；其中 5 组都改正了注释（KR 1949、KP 1956/1958/1967/1972、
  CN 收费、KR 1969/1974、RU 1984），**没有因此改动行为数值**。唯一改动是 KR 1950—1952 的
  `compulsoryYears` 0 → 6（1949 年《教育法》已定六年义务教育），经黄金指纹与 CLI 投影测试确认无行为变化。
- **缺口**：15 段的 `passBase`/`feeShare` 全部没有来源；JP 全部结构值、RU 1950—1983 与 1992+ 结构值、
  CN 1950—1985 结构值、KP 1972 年前的学制值仍无直接来源。缺口表见 §6。
- 与 M3-012c 的基线一致：`pnpm verify` 与 `PW_CHANNEL=chrome pnpm test:e2e` 全绿，黄金指纹与
  CLI 主角投影未变（见审计文档）。

## 2. 等级口径

DATA_POLICY 的等级是**每个统计值**的元信息；国家包的 `EducationSegmentSchema` 只有**一个** `grade`。
本文件按下面的口径解释：

| 标记           | 含义                                             | 在本文件里的用法                                   |
| -------------- | ------------------------------------------------ | -------------------------------------------------- |
| C（法规/史实） | 已登记来源的文本直接支持该值                     | 例如「1949 年《教育法》第 8 条：六年初等义务教育」 |
| D（设计假设）  | 没有来源，或来源只支持相邻事实；数值为可玩性取值 | 例如 `passBase`、`feeShare`、多数入学年龄          |
| 待核实         | 有常识性说法，但本轮没有取得可引用文本           | 例如 JP 六三三四、《学校教育法》原文               |
| 无来源         | 连可引用的间接来源都没有                         | `passBase`/`feeShare` 的全部取值                   |

**段级 grade 为什么仍是 D**：C 级要求整段可引用教育法规来源；这 15 段每段都至少有一个
纯设计参数（`passBase` 或 `feeShare`），按最弱值取 D 比把整段标 C 更诚实。ADR-0007 增补的
「能引用来源的年份为 C」在本任务解释为「该年的结构值有 C 级证据」，逐值登记在 §4；如果维护者
要求按年份整体升降级，需要一次明确的等级口径决定（列入 §8）。
