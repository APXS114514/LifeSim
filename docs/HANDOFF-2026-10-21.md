完整原始报告：[改动前](audits/benchmarks/M3-043-before.json)、[角色版本](audits/benchmarks/M3-043-after.json)。

G1 要求 p50 ≤ 5.5 ms，两个版本都未通过。角色版本增加约 18.4%，不能只归因于机器差异。CPU 采样约 24% 用于 JSON 复制、20% 用于结构比较；采样包含事务、公开只读副本与基准快照，不是各函数精确计时。

接手后先按已批准 ADR-0011 在隔离分支实现按需复制，保留随机流、普通 JSON 快照、所有校验和失败回滚，并验证外部引用不能修改已提交状态。不要改阈值、删事件、降概率、缩短年龄窗口或减少属性测试次数来压性能。优化前后应对同一规则版本重新测量，年度重点新增审计后不能直接把旧工作量指纹当作新基线。
