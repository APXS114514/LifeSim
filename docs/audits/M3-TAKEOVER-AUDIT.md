## 2. CI 失败根因（P0，已修复于 M3-035）

逐提交在同一台机器上测量（Apple M5；`pnpm bench --lives 1000`；覆盖测试单独运行）：

| 提交                   | p50 ms/局 | 平均事实数 | 覆盖测试 |
| ---------------------- | --------- | ---------- | -------- |
| `ee4624d`（最后绿灯）  | 1.77      | 76.9       | 926 ms   |
| `1a9c9e3`（M3-010 前） | 1.82      | 76.9       | 992 ms   |
| `48ca301`（M3-010）    | 4.34      | 79.4       | 1,490 ms |
| `e19901a`（M3-009）    | 4.35      | 79.4       | 1,561 ms |
| M3-035 分支            | 2.72      | 79.4       | 1,142 ms |

逐项回答维护者的问题：

1. **CI 波动还是真实退化？** 真实退化：M3-010 让单局成本升到 2.4 倍，而事实数只多 3%。CI 本身也慢（本机完整测试 5.1 s，CI 的测试步骤 23 s，约 4.5 倍），原来就离 5 s 不远。
2. **重复计算？** 没有。200 局各模拟一次、各渲染中英一次；真实 RU 人生约 45 ms。
3. **测试是否完成、只是超时？** 是。本机单独运行与完整并行运行都通过，断言全部成立。
4. **异常长事件链？** 没有。200 局平均 78.8 条事实、最多 111 条。
5. **M3-009/M3-010 是否增加了不必要的计算？** M3-009 几乎没有影响（4.34 → 4.35）。M3-010 规则本身很便宜；成本来自内核：每个事件对**全部**角色做 zod 校验（49%）并深拷贝整份状态（28%），角色从 1 个变 3 个，成本线性增长。ADR-0004 曾写明「M3 引入 NPC 后重新测量」。
6. **测试并发的资源争用？** 有影响但不是根因：并行运行时同一测试慢 10%—60%，CI 的 4 核机器上更明显。

修复（M3-035，分支 `task/M3-035-kernel-incremental-verify`，提交 `45e1948`）：内核只校验本事件新增或改动的角色与账户；`cloneJson` 正常路径不拼接路径字符串；该测试单独设 20 s 预算并注明依据。黄金指纹、基准工作量指纹与全部事实逐字节不变。新性质测试顺带发现 `cloneJson` 会静默丢弃自有键 `__proto__`（M1 起存在，目前不可达），已改为报错。详见 [tasks/M3-035.md](../tasks/M3-035.md)。

**流程教训**：M3-009 / M3-011 任务的性能门槛写成「p50 不超过 M3 前的 3 倍」，2.4 倍的退化因此没有被任何人拦下。M3-011 已改为以 M3-035 后的 2.72 ms 为基线、5.5 ms 为停止线；建议每个任务报告都附 `pnpm bench --lives 1000` 前后对比。

## 5. 历史名称、旗帜与 M3-033

- **名称与旗帜按日期、政体与地点解析**：`flags.ts` 以政体 ID + 日期选旗（苏联 1955-08-19 换版），`display.ts` 按地点与日期解析名称（列宁格勒 → 圣彼得堡）；都没有按出生国家写死。7 个旗帜文件的 SHA-256 与 `FLAG_SOURCES.md` 一致，均为 Commons 公有领域，未使用 1injp 素材。
- **苏联范围**：出生选择写「俄罗斯（含苏联时期）」，没有假装支持其他加盟共和国。但苏联时期的人口池地点显示为「其他城镇地区，苏联」，容易被理解为苏联任意地区（实际只覆盖俄罗斯苏维埃联邦社会主义共和国的范围）（P2：建议在 RU 包里给苏联时期的地点加 RSFSR 名称，属数据任务）。
- 旗帜小瑕疵（P2）：韩国、日本、俄罗斯联邦在全部年份使用现行规格（太极旗 1949/1984 规格、1999 年日章旗法、1991—1993 年俄联邦旗比例不同）。
- **M3-033 只有设计文档，没有任何代码**，不能报告为已上线。设计审查发现两处史实问题，在提交 Q10 审校前必须修订（P1）：
  1. 推荐的唯一窗口 E（1955—1960「晚期零星北上」）所引的个案来源 S5（越北作家）。据审计者所知，这类人物多在 1945—1950 年代初北上，不能证明 1955 年后的南→北迁移；需要逐句核对 S5，找不到 1955 年后的可靠来源就不能保留窗口 E。
  2. 叙事草稿写 1958 年「火车开动」北上。1953 年停战后军事分界线封闭，南北之间没有铁路客运，这个情节与史实冲突。同期规模较大的北上是 1959 年起从**日本**出发的在日朝鲜人「归国」，那属于 JP 包，与南→北不同。
- 本节涉及的朝鲜半岛内容仍受 Q10 约束；审计者没有修改设计文档的结论，只在文档顶部加了审查意见。
