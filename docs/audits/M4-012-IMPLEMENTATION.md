# M4-012 国家包按需加载实现报告

状态：本地实现与验证完成，位于 `task/M4-012-resume`；国家包入口改动仍需维护者审查，尚未推送。

## 实现

- `country-packs` 保留 Node / CLI 的同步入口，增加 `browser` 条件入口；浏览器初始包集合为空，指定地区只导入所需国家，随机地区显式加载全部五国并报告进度。
- 加载器合并并发请求，失败不缓存；界面有双语错误和刷新重试，保留失败开局的种子与选择。
- 五国的非统计元数据原样移入轻量 `.meta.ts`，供出生页旗帜与地理预览使用。元数据逐字段相等、数据指纹不变。
- 部分国家可独立建查询索引。已加载集合增加时，真实地区适配器重建索引；加载失败不当作损坏存档，不删除或覆盖原始数据。
- 反思、指标与原有存档失败保护继续保留。
