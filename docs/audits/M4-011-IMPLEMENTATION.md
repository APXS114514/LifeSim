# M4-011 离线支持实现报告

状态：本地实现与验证完成；Service Worker 与构建配置改动待维护者审查，尚未推送。

## 行为与版本边界

- 初次联网缓存应用外壳、样式、图标、许可和清单；国家统计块仅在实际加载时缓存。已缓存国家支持断网刷新、恢复存档与继续推进；未缓存国家有双语提示，并可返回选择已缓存国家。
- 缓存版本由全部构建文件及 worker 源码的真实内容计算，独立于存档版本。新 worker 不自动替换正在运行的版本，页面提供明确更新按钮；更新前保存失败时保持页面与内存进度。
- 激活后仅清理同一部署路径下的旧缓存。另一标签页仍使用旧代码时，未知版本的资源块返回 409 并提示更新，避免混用。
- 运行时缓存写入失败不会把成功联网响应变成失败；页面会提示离线存储不可用。注册不支持或失败时仍能在线游玩。
- 所有缓存请求限于当前来源和应用范围，不缓存远程 API，不增加外部字体、遥测或依赖。
- 普通许可文件链接保留原始文档响应，离线时仍可阅读；仅应用根路径与 index.html 使用应用外壳。
