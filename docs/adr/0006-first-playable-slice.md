# 0006：第一个可玩切片（M3-lite）

- 状态：提议（首个可玩测试版本；待维护者审查）
- 日期：2026-10-20
- 关联：ADR-0004（确定性内核）、ADR-0005（M2 数据架构）

## 背景

M2 已完成五国地理、币制、历史锚点、统计序列、DataRegistry 与出生选择器，但 systems 仍只接合成地区 ZZ-SYN。GDD 的 M3 要求家庭、NPC、婚育、迁居、城市权重和各国特色事件；这需要新的数据与规则，不能用一个版本完成。

为了让维护者与测试者尽快玩到真实历史骨架上的完整人生，本 ADR 定义一个**可玩切片**：不改变 M1 的事件引擎与 M2 的数据格式，用一个适配器把国家包接入现有 RegionModel，并提供一个网页界面。它不是 M3 的完成，而是 M3 的第一个可运行子集；后续 M3 工作会替换这里的 D 级规则。

## 决定

### 1. 适配器位置

新增 @lifesim/real-world，依赖 country-packs、data-registry、systems、simulation-core、content-schema、narrative。它：

- 用国家包的 placeId、polityId、币制与锚点构造 RegionModel；
- 用国家包的 births / life-table-qx / urban-share 序列回答出生权重、生命表与城镇比例；
- 把 polity-change 锚点**排除**在人物模拟的锚点之外（见第 4 节）；
- 其余 RegionModel 数据使用本 ADR 列出的 D 级设计假设。

### 2. 证据与数据边界

- mortality 表：B 级，来源 un-wpp:2024，覆盖 1950—2100；2100 年以后用 scenario-hold-last（D 级、projected: true）。
- population / urban-share：B 级，来源 un-wpp:2024 与 worldbank-wdi:SP.URB.TOTL.IN.ZS。
- illness、education、labor、prices、history：**D 级**，来源 adr:0006，因为它们不是历史统计，而是让切片可玩的规则假设。
- 适配器不会把 D 级数值写成真实国家的统计事实；叙事显示“慢性病”“找到工作”等事件，不宣称这些概率是官方数据。

### 3. D 级规则基线（可替换）

所有五国共用同一组规则；后续 M3 按国家/年份拆分。数值以“可玩、内部一致、可测试”为目标，不是历史估计。

- 学制：小学 7 岁起 6 年，中学 3 年，大学 4 年。
- 工作/退休：16 岁起可工作，60 岁退休，养老金为同学历工资的 75%。
- 小学入学：城镇 0.97，农村 0.90。
- 升中学：低/中/高家境 0.45 / 0.75 / 0.95，农村再减 0.10。
- 大学录取：0.10 + 0.60 × aptitude，上限 0.90。
- 求职：无学历 0.55、小学 0.65、中学 0.80、大学 0.92；衰退再乘 0.50。
- 失业：正常 0.03，衰退 0.12。
- 慢性病发病：35 岁前 0.0005；之后 0.002 + 0.001 × (年龄−35)，上限 0.08。
- 死亡乘数：未治疗 1.8、已治疗 1.15、贫困 1.25、大学 0.8。
- 家庭资源：low 0.25 / middle 0.55 / high 0.20。

工资与价格（D 级，仅用于切片）：

- 每个币制版本 1 的年工资基数（整数最小单位）：CNY 1,000,000,000；JPY 250,000；KRW 5,000,000,000；KPW 10,000,000,000；RUB 10,000,000,000。
- 工资按 1.04^(year−1950) 的指数增长，再按出生前/后的币制重定值逐次换算到当前版本；学历乘数 none 0.45、primary 0.60、secondary 1.00、tertiary 1.60。
- 生活费为同学历工资的城镇 0.40 / 农村 0.28；一次性治疗费为 0.15 倍工资，年度持续费为其 0.20；1980 年起可获得治疗。
- 这些数值不是各国工资统计；M3 接入真实工资/价格数据时必须替换并写新的 ADR 或更新本 ADR。

### 4. 首个切片的明确限制

- **只有主角**：没有 NPC、家庭、婚育、收养、迁居、城市权重或国家特色事件；主角死亡即结束。
- **政体只在出生时确定**：适配器用出生日期的政治实体初始化主角；polity-change 锚点不在人物模拟中触发，因此 1991 年前出生的俄罗斯角色不会在 1991 年自动改国籍。该效果留给 M3（GDD §5）。
- 城市只作为地理实体存在；出生选择仍在“其他城镇/其他农村”人口池之间按 urban-share 分配（与 M2 一致）。
- 网页首版在主线程同步运行（80 年人生实测远低于 1 秒）；Worker、IndexedDB、PWA 与时间线虚拟化属于 M4。
- 存档是本地 localStorage 中的快照 + 事实日志；刷新可继续，但清空浏览器数据会丢失，导出/导入与 IndexedDB 属于 M4。

### 5. 何时重新评估

- M3 接入真实教育、就业、价格、疾病数据时；
- 需要把政体更替作用到在世角色、加入家庭/NPC 或城市权重时；
- 网页需要 Worker/IndexedDB/PWA 时（M4）；
- 维护者决定角色性别、迁移或国家特色事件时。

## 后果

- 首个可玩版本可以完全离线运行，且不新增外部数据许可风险；
- 所有非死亡率数值都明确标为 D 级，不会伪装成历史统计；
- 适配器是 M3 的临时边界：真实规则替换时，网页与 CLI 的调用方保持不变。
