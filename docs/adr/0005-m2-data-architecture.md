# 0005：M2 数据架构

- 状态：已采纳（M2 任务据此拆分，见 [docs/tasks/INDEX.md](../tasks/INDEX.md)）
- 日期：2026-10-20

## 背景

M2 要建立五个真实地区的数据包与证据登记（GDD §13 M2、阶段 2 任务）。后续编码主要由轻量 Coding Agent 按小任务完成，因此数据的形状、存放位置、回退规则与许可门禁必须事先定死，不能交给执行者临场设计。

## 决定

### 1. 包与职责

| 包                       | 职责                                                                                                            | 依赖                                           |
| ------------------------ | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| `content-schema`（扩展） | 统计序列 `StatSeries`、地理（`PoliticalEntity`、`AdminUnit`、`Place`、`PlaceAssignment`）、`polity-change` 锚点 | zod                                            |
| `data-registry`（新）    | 按（指标、地理、年、年龄）查数；回退规则；断点；投影与情景标记；绝不把缺失当 0                                  | content-schema                                 |
| `country-packs`（新）    | 五地的包定义（地理、币制、锚点、断点、序列）、包校验、出生选择器                                                | content-schema、data-registry、simulation-core |

依赖方向已登记在 `scripts/check-boundaries.mjs`。**`systems` 与 `RegionModel` 在 M2 不改**：真实地区接入人生规则（适配器、在世角色的政体更替、城市权重）在 M3 进行。

### 2. 数据从哪来、放在哪

| 阶段     | 位置                                                                                                 | 进仓库吗                             |
| -------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------ |
| 原始下载 | `data/cache/`（已 gitignore）                                                                        | 否                                   |
| 输入登记 | `data/scripts/<来源>/inputs.json`：文件名、官方 URL、SHA-256、获取日期                               | 是                                   |
| 转换脚本 | `data/scripts/<来源>/*.mjs`（Node，无第三方依赖；通用工具在 `data/scripts/lib/`）                    | 是                                   |
| 派生数据 | `packages/country-packs/data/<packId>/<来源>-<指标>.json`，每个文件是一个通过 schema 的 `StatSeries` | **只有在来源许可核验为可再分发之后** |
| 来源登记 | `data/sources.json`（机器可读，生成 `data/SOURCES.md`）与 `data/LICENSE_AUDIT.md`                    | 是                                   |

国家包用带 `with { type: 'json' }` 的 JSON 导入读取派生数据，保持与运行环境无关（Node 与浏览器都能用）。

### 3. M2 只引入能可靠获取的数据

| 指标                         | 来源（待许可核验）                                  | 证据等级                       | 覆盖                |
| ---------------------------- | --------------------------------------------------- | ------------------------------ | ------------------- |
| `births` 年出生数            | 联合国 World Population Prospects 2024，Medium 方案 | B（模型估计）；2024 年起为预测 | 1950—2100           |
| `life-table-qx` 单岁死亡概率 | 同上，**男女合计**                                  | B；2024 年起为预测             | 1950—2100，0—100 岁 |
| `urban-share` 城镇人口比例   | 世界银行 WDI `SP.URB.TOTL.IN.ZS`                    | B                              | 1960 年起           |

- **只用男女合计的生命表。** GDD 没有规定角色是否有性别；是否加入性别是产品决定，待维护者决定后另立 ADR。
- **城市人口暂不引入。** 联合国城市化展望的城市数据是 Excel 格式，解析方式与许可都未定；M2 中代表性城市只作为地理实体存在，随机出生只在「其他城镇 / 其他农村」两个人口池之间按城镇比例分配（GDD §4.3 的回退规则）。城市权重留到 M3。
- **不虚构数据。** 没有可靠来源的数值写 `null` 并说明原因；唯一允许的推算是下面明确声明的规则，结果标为 C 或 D 级。

### 4. 回退规则（GDD §9.2 的落地）

按顺序尝试，第一个成功的返回，并在结果里写明用了哪条规则：

1. **精确值**：同指标、同地理、同年（、同岁）。
2. **相邻年份**：同地理同岁，与目标年相差不超过 2 年，且两者之间没有断点；取最近的，同距离取较早的年份。证据等级降为 C，方法 `fallback-neighbor-year`。
3. **上级地理**：地点 → 所在国家，同年精确值。证据等级降为 C，方法 `fallback-parent-geography`。
4. **指标专属的声明规则**：只有登记在案的规则才能用。M2 只有一条：`urban-share` 在最早观测年之前最多向前沿用 10 年，证据等级 D，方法 `hold-first-observed`（用于 1950—1959 年）。
5. 都不行则返回缺失（`value: null` 与原因）。**调用方遇到缺失必须报错或走声明过的处理，不能当 0。**

预测年份（WPP 2024 中 2024 年起）照常返回，并带 `projected: true`。超出序列末年（2100 年以后）默认返回缺失；调用方显式要求时才用情景规则 `scenario-hold-last`（沿用末年值，D 级，`projected: true`）。

### 5. 断点

断点（政体更替、币制改革、统计口径变化）由国家包登记。相邻年份回退不能跨越断点：断点日期所在年为 b 时，从 y₁ 回退到 y₂ 当且仅当 min(y₁, y₂) < b ≤ max(y₁, y₂) 时视为跨越。

### 6. 许可门禁

- 任何派生数据文件进仓库之前，它的来源必须在 `data/sources.json` 里标为 `redistribution: "allowed"` 且有 `verifiedAt`，并在 `data/LICENSE_AUDIT.md` 记录条款原文出处。许可核验由维护者确认（高风险任务）。
- `scripts/check-data.mjs`（M2 任务中建立）在 CI 中检查：国家包引用的每个来源都已登记；派生数据只来自可再分发的来源。

### 7. 出生选择（GDD §4.3）

- 随机年份：1950—2026 等概率。
- 随机地区：只在五个首发地区之间，按该年 `births` 加权，P = Bᵢ / ΣBⱼ；任一地区该年出生数缺失时报错，不跳过、不当 0。
- 地区内：先按 `urban-share` 抽城镇 / 农村，再落到对应的人口池地点；日期在该年内等概率。
- 随机流固定为 `deriveStream(seed, 'birth-selection')`，抽样顺序固定，手动指定的项也照常抽样，保证其他抽样不错位（与 M1 出生事件相同的约定）。

## 何时重新评估

- 维护者决定角色是否有性别时；
- M3 接入城市人口数据或真实地区人生规则时；
- 任何来源的许可核验结论为「不可再分发」时（需要改用其他来源或只在本地使用）。
